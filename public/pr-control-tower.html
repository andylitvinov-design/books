Как читаются показатели. Открытые и созданные PR считаются по GitHub Search; merge — по GitHub merged-фильтру. «CI выполняется / ждёт» — число workflow runs, а не individual jobs или занятых раннеров. «PR в активной обработке» — наблюдаемый минимум из отдельных PR, связанных с выполняемыми runs, и действующих work leases из ограниченной выборки CI Triage. «Готовы к merge» — только подтверждённые exact-head кандидаты в канонической очереди, а не проверка всех PR. «Merged» не означает «LIVE»: развёртывание на Vercel отслеживается отдельно. При отсутствии данных числа не подменяются нулями. Содержимое страницы только читает публичный GitHub API, не хранит токены, не создаёт PR, не запускает CI и не изменяет репозиторий.
