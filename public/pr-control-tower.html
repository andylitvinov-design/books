Очередь Triage ↗
Как читать показатели и насколько они точны

«Новые» и «Merge» — события за 60 минут до каждого замера, не коммиты. Нельзя складывать их между неполными или нерегулярными измерениями и считать точным итогом календарного дня. «CI идёт» и «CI ждёт» — число workflow runs, а не занятых раннеров и не отдельных jobs. «PR в обработке» — минимум распознанных PR в CI и подтверждённых рабочих leases; не полный учёт работы всех исполнителей. «Готовы» — только проверенные PR из ограниченной выборки Triage. Цвет верхней границы карточки — оценка нагрузки CI, не правило блокировки merge. Новые PR не запрещены; при высокой нагрузке разумнее избежать одновременного массового push. История строится из GitHub Triage и локальных снимков браузера, пропуски не заполняются придуманными числами. Merge не означает deployed/LIVE. Страница только читает GitHub API и не запускает проверки. Данные этого часа могут обновляться в течение часа.
