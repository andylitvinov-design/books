# TempleTherapy Maya and Aztec search archive

This folder preserves public HTML returned by Telegram's unauthenticated search pages for the public `@TempleTherapy` channel, using the queries `майя`, `ацтеки`, and `ацтек`.

`TEMPLETHERAPY_MAYA_AZTEC_INDEX.jsonl` is a deduplicated, message-level index of results whose text explicitly concerns Maya or Aztec traditions. `source_query` is an array when one post appeared in more than one query response. `media_references` records only URLs embedded in the public HTML; no remote media was downloaded or copied. Where a message contains an embedded photo, `media_caption` reproduces its accompanying post text; otherwise it is `null`.

This is a public, supplemental source archive—not a primary source or a scholarly authority. It must not be treated as evidence of historical, archaeological, linguistic, or religious claims without independent primary and academic sourcing.
