# Agent Commander: дерево задач → открытые PR (HH_PR_TASK_TREE_V1)

Срез анализа: 7 ноября 2026, public GitHub repo andylitvinov-design/books. В ходе проверки было 132 открытых PR (количество меняется; #3866 позднее merged). Все 132 были тематически назначены без дублирования по семи направлениям и 29 подзадачам. Категории и номера, зафиксированные на момент аудита, находятся в pr-task-tree.js; будущие PR классифицируются предварительно по названию/меткам, не теряются и помечаются как предварительные.

## Пользовательский маршрут

Пять нижних вкладок Commander остаются. Во вкладках «Задачи» (/project-management-public.html) и «Проекты» (/projects.html) появляется раскрывающееся дерево: направление → задача → кликабельные номера открытых PR и названия. Доступны фильтр, ручное обновление и краткие различимые статусы Draft, HOLD, ручная доработка, открыт. Кандидаты на сверку: Goal (#3826, #3782, #3774), Safari (#3836, #3833), Android (#3121, #3111), Рейки (#1634, #1605). Это не доказательство дублирования и не разрешение на закрытие PR.

Данные: только публичный GitHub GET /repos/.../pulls; все страницы до <100, защитный максимум 6, отказ при неполной пагинации/двойных номерах. Полный снимок обновляется при открытии вкладки или по кнопке, не чаще 15 минут автоматически за счет sessionStorage, **без фонового polling/cron/новых API серверов**. При ошибке сохраняется явно помеченный старый снимок (до 1 часа) либо честное «данные недоступны». Никаких GitHub write credentials, действий с merge, CI или деплоем. Статус «Открыт» не означает green/mergeable. Контрольная база, production база и stacked PR посчитаны раздельно.

## V1.1 · уровень задачи

Групповая задача имеет консервативный статус по своим открытым PR (HOLD/на доработке/в разработке/ожидает проверки). Внутри — «Проверить задачу»: только по нажатию перечитать текущие PR HEAD, без автоматического CI/merge. Для не-manual и не-Draft проверяется существующий exact-HEAD Merge Gate с публичным HHPMProof; неизвестные проверки остаются UNKNOWN. Отчёт включает количество проверенных PR и пометку, что LIVE не подтверждён. Действует лимит 12 PR за одно нажатие; ошибок и частичного покрытия не скрывать. Кнопка «ТЗ проверяющему агенту» копирует структурированный запрос, **но не запускает агента** в публичном кабинете. Запуск и сохранение частных отчётов — только через защищённую авторизацию владельца.
