# PR Monitor: 503 recovery, three KPI cards, ChatGPT scope

The separate monitor is currently manually deployed to Vercel (not the Holistic House site). The primary CI source remains `/api/ci-queue-detail`. If it fails with 503 or incomplete data, the UI can perform at most five public, read-only GitHub Actions status lookups (`in_progress`, `queued`, `pending`, `waiting`, `requested`). These are workflow counts **for the repository**, never PR or runner/job counts. Missing queue status reads render a lower bound (≥), never an invented zero. A verified fully covered backup snapshot is cached for 3 minutes, retained at most 15 minutes, and labeled by its age. No scheduled calls, paid providers, tokens or CI reruns.

The overview renders **CI в работе | CI в ожидании | GPT-агенты** as one row, with full GPT scope/time below. The GPT value comes from existing public issue #2876 aggregate `HH_CHATGPT_AGENT_ACTIVITY_V1` and counts **last observed running scheduled ChatGPT automations only** (at 17:04 Toronto: 15 enabled / 15 observed / 1 running). The account-wide number of simultaneously working manual chat conversations, Work tasks or subagents cannot be determined from the available authorized ChatGPT API. Do not infer it from chat count, or show a fabricated total.
