# HH_PR_CONTEXT_COMMENT_V1 · комментарии внутри задач и PR

**7 ноября 2026 · Agent Commander · control branch codex/bootstrap-books**

## UI
В главных карточках /project-management-public.html, а также в раскрываемом дереве задач на страницах «Задачи» и «Проекты», каждой задаче (в том числе без PR) и каждому PR назначается значок 💬. Он раскрывает inline text textarea, кнопку 🎙 голосового распознавания с keyboard-dictation fallback и «Отправить в работу». Расшифровку можно редактировать. Аудиофайлы приложением не хранятся; браузер/ОС могут использовать собственную службу распознавания.

## Контекст и история
После явного нажатия «Отправить» выполняются только bounded GitHub GET для первых трёх связанных PR: исходное тело PR, base, OPEN/DRAFT/MERGED, exact HEAD, last commit, текущие check-runs, последние доступные комментарии. Все номера связанных PR передаются в protected same-origin handoff. Прочие PR агент обязан перепроверить. Частичные/недоступные данные помечаются UNKNOWN, никогда не выдаются за PASS/LIVE. На защищённой странице при настроенном приватном хранилище загружается до 8 связанных предыдущих private tasks (исходные тексты, планы, state, updatedAt); остальные должны читаться исполнителем по ссылкам. Для задач без PR доступен контекст проекта, этапа и статуса; отдельного идентификатора private task может не быть.

## Авторизация и граница реального запуска
Публичная карточка не пишет PR комментарии в GitHub, не хранит приватные тексты и не запускает workflow. Передача открывает same-origin защищённый task-editor с редактируемым промптом и связанными PR; владелец проверяет и сохраняет. Существующий /api/commander-drafts action=queue гарантирует только QUEUED_FOR_REVIEW, agentStarted:false; отдельное доверенное execution gateway всё ещё требуется для реального старта. Никогда не отображать состояние «агент работает», пока нет доказанного executor run.

## Внедрение
Требуются проверки Node tests, браузерная проверка текста/голоса и denied mic на Safari при 320/390/430 px, privacy/owner auth, редактирование и private readback. PR только в защищённую control branch, exact-head checks, merge. Standalone Vercel PR Monitor вручную развернуть из полного существующего deployment manifest, не из частичного GitHub архива. GitHub merge не означает LIVE.
Без новых платных сервисов, cron, extra CI polling и обхода protected gates.
