# Ali Learning Studio — synthetic Case Lab v1 (#4797)

Owner-only /admin/learning/cases is a first-party editor with nine authored synthetic seed examples, exact-tag retrieval preview, and an isolated set of 60 candidate evaluation scripts (20 per locale, five user turns each). No provider or customer transcript is read, and no local model is required. Every seed is REVIEW_REQUIRED; none is injected into runtime. Draft editor stays in browser memory, rejects common contact/secret patterns (not a proof of anonymization), and exports a review-required JSON file only after explicit synthetic attestation. Do not export real client content. No database schema changes or client analytics.

A protected source-controlled review is the publication boundary; this release has no server draft persistence or auto-promotion. To evaluate, run `node scripts/ali-learning-evaluate.mjs` against a checkout, save its JSON locally, compare exact same corpus hash for baseline/candidate; the runner exercises only the offline native and Telegram fallback, stops a script if the host is required, never invokes a provider. Human role/safety/semantic review, real host+channel E2E, and signed delivery remain required. Source test suite checks schema, leakage by family/ID, export safety, and synthetic adapter behavior; this is not a 90/100 result or proof of 60 passing conversations. Keep evaluation scripts separate from training examples. No Colab or Mac availability needed. Cloud persistence/editor approvals and runtime reviewed retrieval are further work, not implied by an export.
