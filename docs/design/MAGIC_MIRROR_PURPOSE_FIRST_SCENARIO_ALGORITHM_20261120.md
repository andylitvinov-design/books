# Magic Mirror — сценарий по цели пользователя (20 ноября 2026)

## Единый маршрут (RU/EN/ES)
Категория → Подкатегория → Тема → **Цель** → **Персонализация под цель** → Концепт/сценарий → существующий Монтаж/MP4.

Тема — о чём сюжет, цель — зачем он нужен и каким способом подавать сообщение. Пользователь сам выбирает категорию, подкатегорию и тему из действующей таксономии 4×4×4. Название темы сохраняется в креативном задании; никакая последующая цель не меняет `topicId`. Определение темы из свободного текста допускается только как предварительное предложение, требующее подтверждения при неоднозначности.

## Три постоянные цели в этом порядке (нет динамической сортировки)
1. `rest` / `leisure`: «Отдохнуть и расслабиться». Приятная эстетика, бережный темп; никакой обязательной смены убеждений, «я»-аффирмаций или внушений. Голос/текст опциональны, механизм `restful_pause`.
2. `accept` / `support`: «Получить эмоциональную поддержку»; видеообращение с тёплыми словами во **втором лице** — «Ты важен», «Ты достоин заботы». «Я тебя люблю» — только если посетитель явно выбрал формат «Слова любви», и это художественный текст видео, а не реальное обещание отношений. Механизм `validation`.
3. `reframe` / `change`: «Изменить установки и отношение к себе». Бережная работа с самоописанием и перспективой в **первом лице**: «Я могу выбирать», «Я имею право быть собой». Не навязывать убеждения и не обещать излечения. Механизм `cognitive_reframing`.

Три карточки отображаются всегда. Упразднена вторая страница дополнительных целей, не изменяются видео-источники, 30-секундный хронометраж, рендер и лицензирование.

## Адаптивная персонализация — только необходимые вопросы
| Цель | Шаги |
|---|---|
| Отдых | Желаемое чувство → энергия сейчас (1–10) → имя (необязательно) |
| Эмоциональная поддержка | Чувство сейчас → желаемое чувство → **какая поддержка нужна** (принятие, забота, спокойствие, близость, подтверждение ценности, слова любви) → энергия сейчас (1–10) → имя (необязательно) |
| Изменение установок | Чувство сейчас → желаемое чувство → **смысловой вектор** (существующие оси) → энергия сейчас (1–10) → имя (необязательно) |

«Сколько энергии сейчас?» — ровно одна оценка от 1 до 10; не предустанавливать балл за человека. Для отдыха не спрашивать убеждения и негативное исходное состояние. Для поддержки не спрашивать смысловой вектор. Смысловой вектор обязателен только в цели `change`. Название уже подтверждённой темы показывается как контекст вопросов. Не использовать выбранные по умолчанию значения как подтверждённые симптомы.

## Генерация сценария
```text
input = { categoryId, subcategoryId, topicId, wish, goalId,
          currentState?, desiredState?, supportNeed?, meaningAxis?,
          energyNow?, preferredName? }

canonicalGoal = one_of(rest, accept, reframe)
goalPlan = { type, mechanismId, voicePerson, scenarioStrategy,
             secondaryScenarioStrategy, meaningAxisId, topicId }

concept = existingVideoConceptGenerator(
  originalWish + selectedGoalIntent,
  confirmedTopic,
  confirmedPersonalization,
  goalSpecificCaptions,
  requestedDuration
)
storyboard = existingAutomaticStoryboard(concept, 30s, 6 scenes)
preview/export = existingSingleCanvasAndMP4Pipeline(storyboard, captions)
```

В 30-секундном сценарии использовать исходные 4 эмоциональные фазы и 6 кадров по 5 секунд, но адаптировать драматургию:
- Отдых: пауза → дыхание/созерцание → расширение пространства → мягкое завершение.
- Поддержка: контакт → признание потребности → подходящие тёплые слова → ощущение возможности опоры.
- Изменение: существующая ситуация без диагноза → альтернативный взгляд → выбранная «я»-фраза → маленькое реалистичное действие.

Никаких сведений о чувствах и диагнозах, не подтверждённых посетителем. Меняя цель, сбрасывать автоматическую персонализацию и устаревшие черновики, сохраняя тему. При возврате к той же цели не стирать вручную отредактированные фразы. `contextKey` цели не должен зависеть от последующих ответов, чтобы выбранная цель не пропадала по ходу опроса.

## Эксплуатация и приёмка
- Контент локализован на RU, EN и ES, панели адаптированы для 320/354/390/430px, кликабельные области 44px+.
- Итоговые выбранные фразы реально попадают в **тот же** предпросмотр, текстовый редактор, голосовую дорожку (если включена) и экспортируемый MP4. Запрещено дублировать рендер и звук.
- Поддерживающее видео не является диагнозом, обещанием терапии или заменой индивидуальной психологической помощи.
- Нет новой таблицы, внешних ИИ-запросов, платных провайдеров, локального компьютера или скрытой отправки анкет.
- Проверить исходный маршрут Goal taxonomy → 3 цели → адаптивные вопросы → Concept → Montage → успешный реальный MP4; защитить от регрессии существующими Core, TypeScript, Specialist и Chromium/WebKit CI.
- Развёртывание в `codex/public-book-library` только через штатные защищённые проверки, merge и совпадающий SHA Vercel READY с доменом `holistichouse.vercel.app`. Не утверждать LIVE до проверки.
