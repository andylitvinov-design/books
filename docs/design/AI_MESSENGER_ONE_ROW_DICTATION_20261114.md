# Ali · optional editable native dictation

The primary microphone remains the current instant-send MediaRecorder / Groq Whisper workflow. The + menu offers optional device/browser Web Speech dictation into the existing draft in EN/RU/ES. Consent discloses that the browser speech service may receive audio; no Holistic House recording or API call is made by native dictation. Only final words enter the draft; the regular send action remains separate. Closing the menu, navigation, locale switch, reset, submitting or starting another microphone cancels capture. Unsupported browsers fall back to keyboard dictation. Existing composer styling is preserved, not replaced by the obsolete November 14 snapshot. Exact-head source and browser tests plus physical iPhone acceptance are required; no paid provider or extra deployment.
