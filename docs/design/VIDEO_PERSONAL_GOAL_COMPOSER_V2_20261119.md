# Video Studio · Goal Composer v2 — 3 основные + 2 запасные цели
Дата: 19.11.2026 · технический этап PR #5165 · не означает LIVE

## Продуктовое решение
Сохраняется утверждённый мобильный экран Ideas → Personalization → Goal → Concept:
три большие фотокарточки сразу, «Ещё 2 цели», стрелки, одна кнопка «Выбрать сценарий».
Никаких новых генераторов видео, медиатек, платных API или обращения к медицинской карте.

Только три базовых типа:
1. leisure — отдых, расслабление, развлечение, эстетическое удовольствие.
2. support — эмоциональная поддержка, стабилизация, ресурсирование.
3. change — психологическая коррекция/развитие, мягкое переосмысление,
   осознавание, мысленная репетиция возможного действия.
Три типа — не квоты: при прямом запросе на отдых все пять целей могут быть leisure,
при запросе на психологическую работу первые три могут быть change.

## Три независимые сущности
1. TOPIC: подтверждённая категория → подтема → тема из канона 4×4×4/256.
   Никогда не заменять тему клиента дефолтной целью или старым каталогом.
2. GOAL: результат, который клиент выбирает сейчас, с типом и механизмом.
   Список из пяти предложений (первые три видны; ещё два скрыты).
3. FILM DIRECTION: одна из двух существующих отсмотренных 30-секундных
   историй (6 кадров по 5 секунд); сортировка зависит от GOAL, но
   не подделывает содержание или лицензию материалов.

## Данные
- Приоритет 1: точный текст пожелания (включая ввод на верхнем Goal и requestDraft).
- Приоритет 2: canonical selectedConceptTopic (если реально выбран).
- Приоритет 3: подтверждённые ответы Personalization:
  current[], desired[], axes[], energy, desiredLevel.
- Приоритет 4: общий контекст темы/категории без выдуманных характеристик.
- Реальные диагностические тесты и OPD не читаются автоматически.
  На перспективу использовать только отдельное явное согласие и совместимые
  версии измерений; квиз ≠ клиническая диагностика.
- Имя и закрытые данные клиента не входят в goalPlan, сценарный ранкер или запросы
  сторонним сервисам. Текущий composer работает локально без сети.

## Генерация 3+2
1. Нормализовать локаль RU/EN/ES, запрос, канонический topicId.
2. Определить ведущий intent без диагнозов:
   явный отдых/развлечение > коррекционный запрос > запрос на поддержку >
   выбранная категория > только подтверждённая энергооценка > нейтральный.
3. Выбрать пять разных методических кандидатов:
   leisure: rest, beauty, enjoy, slow, inspire;
   support: ground, accept, resource, reflect, slow;
   change: reframe, strengthen, reflect, rehearse, ground;
   mixed: rest, ground, strengthen, accept, reframe.
4. Название: позитивный глагол + доступный результат.
   Деталь: назначение метода + конкретная подтверждённая тема.
   Intent: тот же результат + текущая/желаемая эмоция + смысловая ось.
5. На Goal показать top3, по «Ещё 2 цели» — оставшиеся 2.
   Явное нажатие клиента обязательно; не выбирать за него автоматически.
6. Хранить выбранную цель вместе с contextKey; смена темы, запроса, шкал
   или локали инвалидирует старый выбор, одобрение и сценарный черновик.

## Матрица Goal → сценарный механизм
Цель            | Первый жанр сценария | Второй жанр
Отдых           | shelter             | integration
Развлечение     | journey             | integration
Красивые образы | integration         | shelter
Стабилизация    | shelter             | integration
Принятие        | shelter             | reframe
Ресурсирование  | integration         | shelter
Осознавание     | reframe             | integration
Переосмысление  | reframe             | journey
Укрепление      | integration         | reframe
Репетиция шага  | journey             | reframe

Это существующие четыре редакторских жанра 256-сценарного каталога:
shelter (тихая поддержка), journey (путь и выбор),
reframe (смена взгляда), integration (интеграция).
Выбранный GOAL даёт ранкеру положительный бонус к совпавшему жанру (+60)
и второй жанр (+24); подтверждённая персонализация продолжает влиять.
Содержимое отснятых кадров и права на них не меняются: плохой/непроверенный
материал не превращается в подходящий от одного совпадения тега.

План (goalPlan) передаётся в общий suggestedConcept → Concept:
getVideoCreativeDirections() → applyVideoCreativeDirection() →
тот же sharedFilmBrief в Montage Storyboard. Не создавать дубликат рендера.

## Ограничения терапевтических видео
30-секундное видео может предложить поддержку, модель мышления или мысленную
репетицию, но не обучает полноценному навыку и не доказывает терапевтический
эффект. Не генерировать автоматическую экспозицию, конфронтацию с травмой,
травматическую регрессию или обещания излечения. Для клинически интенсивной
работы необходимо решение специалиста. Не превращать отдых в психологический
опрос или автоматически читать профиль.

## Сценарные и QA-проверки
- 3 базовых типа, 5 целей, 3 сразу + 2 по запросу, RU/EN/ES.
- В явном leisure все 5 leisure; change — три change сразу;
  support — три support сразу.
- Одно и то же topicId для всех пяти целей; пользовательская тема никогда
  не заменяется искусственной «Спокойствие и баланс».
- Изменить выбранную цель → иной goalPlan → другое ранжирование сценариев
  того же topicId (сохраняется набор из 256 исходных ID).
- Основание персонализации — только подтвердённые значения.
- Смена контекста сбрасывает выбранный id, Concept approval и выбранный фильм.
- UI подтверждает выбор и переходит в Concept; далее единый редактор и Canvas.
- Сценарий не является готовым MP4 до source/rights/codec acceptance.
- Не добавлять cron, платные вызовы, Vercel deploy или новые CI-задачи.
- Node focused tests, TypeScript, lint, Next build и реальное WebKit iPhone QA
  должны пройти на точном HEAD до заявления «LIVE».
