# Монтаж Holistic House · утверждённый мобильный первый экран · 05.11.2026

**Идентичность:** гостевой видеоредактор `/{en|ru|es}/holistic-support/mandala`, вкладка «Монтаж» / `editor`; один Canvas/MP4-превью, текущие API, локальный MediaRecorder, права на фото/аудио и бесплатный режим не изменены.

**Эталон:** последний одобренный пользователем мобильный макет «Настройки монтажа» (тёплый ivory / белые карточки / emerald CTA), с уточнением: четыре кнопки непосредственно под плеером («Настройки», «Эффекты», «Текст», «Аудио») открывают содержимое по одной; при первом открытии активны «Настройки»; монтажной дорожки на первом экране нет; одна нижняя кнопка «Сгенерировать видео».

**Первый экран (320–430 CSS px):** шестипозиционная штатная навигация видеостудии → одно 16:9 видеопревью (без боковых кнопок) → четыре доступных по касанию переключателя → 2×3 параметра (формат/длительность/переходы/темп/качество/стиль) → стоимость и единственная кнопка генерации → штатная нижняя навигация. Интерфейс в токенах Holistic Light #FBF5E9, #FFFCF7, #143D3A, #067A67; мобильный текст не уменьшать до нечитаемого.

**Работа:** настройки связаны с существующими React-состояниями, для многосценного плана переходы обновляют существующий киноплан. Качество HD — реальное 720p, Full HD — 1080p; не выдавать 720p за 1080p. Выбор «Эффекты» меняет существующий источник и яркость. «Текст» открывает исходный редактор сценария, многодорожечный монтаж, SRT/черновик. «Аудио» открывает прежнюю библиотеку, голос, фото и сведение. Никакого отдельного редактора/дублированной генерации. Единственный CTA вызывает прежний `createQuickVideo`, сохраняя проверки прав и устройство-браузерную генерацию.

**Критерии проверки:** осмотр RU/EN/ES 320,354,390,430, WebKit и Chromium: по умолчанию видны 6 реальных полей и один CTA; timeline не виден до «Текст»; переходы между четырьмя панелями сохраняют состояние; выбор 9:16/30s/1080p не уничтожает подтверждённый план; экспорт с прикреплённым звуком и без него; ошибки и disabled; отсутствие горизонтальной прокрутки, перекрытия нижней навигации, авто-рендеров; реальная проверка Safari отдельно. Тесты и READY/SHA/живое E2E записать только по факту.
