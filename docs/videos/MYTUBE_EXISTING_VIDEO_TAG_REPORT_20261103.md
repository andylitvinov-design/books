# MyTube — ранжирование имеющихся видеосцен (3 ноября 2026)

**Область аудита:** каталог подтверждённых локальных MP4-композитов `data/video-catalog/scene-taxonomy.json` (44 уникальных `sceneId`). Двенадцать записей в `free-stock-scenes.json` уже входят в эти 44 и повторно не подсчитываются.

**Основа разметки:** утверждённое дерево 4 категории → 16 подкатегорий → 64 темы → 256 сюжетных концепций. Для каждого фрагмента: одна основная тема и две дополнительные, оценка визуальной уместности 0–100, а для каждой темы — четыре возможных сценарных подхода с отдельной оценкой.

**Ограничение:** баллы — редакционная оценка **визуальной пригодности**, а не вероятность, не результат AI-распознавания видеокадров и не подтверждение содержания готового видео. Ранжирование требует человеческого просмотра прежде чем стать редакционно проверенным. Эта разметка не создаёт 256 готовых роликов и не меняет исходные лицензии, опубликованность или требования к монтажу.

## Покрытие и последующие проверки

- 44/44 локальных утверждённых сцен имеют основной тег; 132 тематические привязки и 528 относительных оценок пригодности к сюжетам.
- Основные назначения неравномерны: Деньги и развитие — 22; Любовь и отношения — 1; Энергия и уверенность — 17; Стресс и тревога — 4. Это свойство доступного медиаматериала, а не план целевого наполнения.
- Публичные записи MyTube/Academy из существующего проверенного индекса получают консервативные теги **на чтении**: точное совпадение названия и фраз даёт тег темы, общие исторические теги дают только подсказку категории. Необоснованные присвоения остаются в состоянии `mytubeNeedsReview`.
- Персональные записи клиента, чужие необследованные ссылки, неутверждённые внешние видео и кандидаты без прав по-прежнему исключены из публичного индекса.
- Для реально готового видео нужны права на материал, проверка воспроизведения, согласованный сценарий/монтаж и редакционная проверка; эта оценка сама по себе не делает концепцию готовой.
