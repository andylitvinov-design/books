**Дата:** 30 октября 2026 · **Статус:** единая инженерная спецификация, проверенный аудит и последовательная программа выполнения для Codex. **Код из этого документа ещё не внедрён автоматически.**
**Репозиторий:** andylitvinov-design/books · **Production:** codex/public-book-library (GitHub default codex/bootstrap-books — НЕ production) · **Сайт:** https://holistichouse.vercel.app · **Маршрут студии:** /{ru,en,es}/holistic-support/mandala.
**Canonical tracking:** https://github.com/andylitvinov-design/books/issues/2397.
**Задача:** развить ОДНУ Video Studio до настоящего гибридного видеопродукта: Free / Smart / Pro; собственная генерация, дешёвые AI-фрагменты, фото, сценарий, голос, музыка, субтитры, 30-секундный мастер, локальное скачивание, приватная доставка и измеряемое качество.

> Обязательная граница: запрещено включать реальные платные вызовы HeyGen/LTX/Kling, менять тариф Vercel, активировать auto-topup, проводить реальные клиентские платежи или публиковать приватные фильмы без отдельных действующих approvals и тестов. Создание кода, mock, quote, бесплатного рендера и docs РАЗРЕШЕНО. Нельзя выдавать 8-секундный AI-клип за готовый 30-секундный Smart или процедурный Canvas за AI neural text-to-video.

## 0. Главные решения — восстановлено из прошлых документов

1. Три **формата производства** на первом экране: **Free / Basic $0**, **Smart $2 USD (предложение)**, **Pro $9.90 USD (предложение)**. Free создаёт реальный видеофайл без paid API. Smart должен содержать один короткий AI-кадр, первоначально 8 секунд, остальные приблизительно 22 секунды составляются из Free-сцен. Pro: на первом HeyGen-контракте один 15-секундный AI-кадр; позднее разрешить несколько кадров, дополнительные аспекты кино-языка и ручной QA. Цены не считать активированным публичным заказом.
2. Отдельная ось **сложности редактирования**: Simple (12 ключевых параметров), Advanced (24), Personal (20 добровольных персональных настроек; накладывается на любой формат), Cinema Pro (40 кинематографических параметров). Сохранить прежние 30 исходных шкал и добавленные 3, всего 33 внутренних значений; не показывать все шкалы клиенту. 96 legacy IDs (49 contextual questions, остальные legacy/demoted) НЕ равны публичной анкете на 96 вопросов. Источник 49 вопросов в утверждённом Google Doc v1.5.
3. **Единый клиентский маршрут**, не второй редактор: идея → оценка условий/приватности → 0–2 уточнения → style bible → раскадровка → выбор Free/Smart/Pro и реальных возможностей → preview → точная стоимость до оплаты → подтверждение → генерация только разрешённых кадров → монтаж с голосом, музыкой, аффирмациями → проверяемый MP4/WebM → скачивание → необязательное приватное сохранение. Отдельный переход в курс/видеосессию.
4. Два независимых пути генерации: **G3a Free local** = собственные Canvas-пиксели / лицензированные MP4, стоимость $0 и без отправки контента; **G3b new AI footage** = новые действительно рассчитанные кадры внешней моделью или подтверждённой локальной GPU, всегда по отдельному request/quote/authorization. Стоковое видео, текст storyboard, PNG/слайд и нейросетевой MP4 не путать.
5. **Гибридная экономика:** оплачиваются только секунды новых AI-кадров и число вариантов, а НЕ вся продолжительность персонального результата. Бесплатные фоны, изображения/портрет на устройстве, оригинальный звук, титры и монтаж добавляются поверх. Если клиент обновляет только одну сцену — не перегенерировать весь ролик.
6. **HeyGen direct Video 1 REST API v3** — ранее утверждённый серверный адаптер, код подготовлен в PR #2625, но переключатели OFF. Прежний OpenRouter-маршрут в черновике superseded, не реанимировать и не подставлять ключи чат-бота. **LTX 2.3 Fast API v2** — рекомендуемый следующий дешёвый адаптер, только как fail-closed разработка/оцениваемый pilot. **Kling 2.5 Turbo** — запасной кандидат/существующий owner-only путь, не автозамена платного запроса.
7. Для клиентской персональной медитации архитектура **Psychologist/Narrative Director → Literary Writer → Independent Editor → Voice Director → Video Director → rendered master**. Для курса из 8 сессий не считать 8 сценариев готовыми озвученными видеомастерами. Реальные сессии и T0/T1/T2 реализовывать после стабильного видеопродукта и профессиональной проверки.
8. **Качество — проверка файлов:** монтаж не фотослайд, звук реально присутствует и слышен, слова титров совпадают с голосом, смещение не 3 секунды; медиа проходит ffprobe/decoded-frame/PCM QA; RU/EN/ES, реальный Safari Save to Files; приватность и платежи idempotent.

## 3. Точная UX-модель одной страницы и модель состояний

**Mobile 320/354/375/390/430:** утверждённый поздний hero PR #2643 + нужные функциональные исправления PR #2566, одна cream/emerald айдентика. Первый экран: компактная Holistic House шапка/один bottom five-tab dock; большое настоящее MP4 preview с Play/Pause; 6 направлений Energy, Money, Relationships/Love, Goals/Meaning, Life/Development, Health/Wellbeing (доп. группы); Free / Smart / Pro без обещаний о пока недоступных оплатах; одно поле «Какое видео вы хотите?»; максимум 2 уточняющих чип-вопроса; один CTA «Подготовить сценарий бесплатно».

После подготовки — четыре начальных shot cards с кратким действием, временем, источником, разрешениями, возможностью Replace/Reorder/Change duration. Формат продакшна выбрать на уровне ролика, а **AI включать только на конкретных выбранных shots**, если клиент хочет действительно новые кадры. Вторая линия компактных панелей (не несколько экранов): Goal/Theme, Photo, Hypno/Affirmations, Visual, Audio & Voice, Format & Export. Для каждого поля одна общая модель данных; отсутствие дублирующих «Моё пожелание», звуковых браузеров, превью или двух кнопок запуска. Параметры Pro/Advanced раскрываются только по намерению клиента.

При выборе Smart/Pro — до получения проверенного server quote показывать «Проект бесплатно, AI-генерация сейчас недоступна». Отключённая кнопка НЕ должна вести к fake success, расходу кредита или отнимать возможность Free.

**Десктоп:** 2 колонки preview/storyboard слева, бриф/опции/price quote справа; мобильный one-column. Touch target >=44 CSS px, subtitle safe-area, VoiceOver, keyboard, reduced-motion, no sticky button over bottom dock; без промо-плашек, скрывающих видео.

**Явные состояния Free:** draft → brief_compiled → storyboard_ready → preview_ready → recording → blob_captured → media_qa_passed → playable/downloadable; failed/unsupported_codec/cancelled/invalidated. Правки после рендера инвалидируют старый Blob или подписывают его как старую revision, никогда не показывают его как свежий. Снятие разрешения на фото останавливает активный фото-overlay.

**Явные состояния paid:** draft → quote_requested → quoted → quote_accepted → entitlement_or_payment_verified → budget_reserved → submitting → submitted → processing → provider_completed → ingested → assembling → qa_passed → delivered_private. Ошибки: quote_expired, unsupported_model, payment_unverified, submit_unknown, provider_failed, ingest_failed, assemble_failed, qa_failed, needs_owner_review, refund_pending. Никакой клиентский «завершено» до playable file и QA.

## 4. Структура VideoProject и компилятор (версионированный контракт)

**Единственный адаптер, НЕ второй source of truth.** Использовать имеющиеся lib/mandala/cinematic-creative-brief.mjs, cinematic-director.mjs, cinematic-production.mjs и editor state; добавить минимальный модуль нормализации. Исходные приватные слова можно хранить лишь в браузерной памяти, а не сериализовать в provider asset/job/analytics.

Предлагаемый TypeScript-контракт, реализовать в новой лёгкой types/manifest, только после сверки текущих типов:

- StyleBible { styleId; palette[]; lighting; period; location; mood; heroDescription:fictional_only; heroIdentityKey; bannedImagery[]; referenceStillIds[]; negativePromptArtOnly; continuityVersion }.
- ShotRecipe { id; order; startMs; durationMs; source:"procedural_canvas"|"licensed_mp4"|"approved_provider_mp4"; motifId; assetId?; sourceLicenseId?; seed; motion; camera; depth; grade; firstFrameRef?; lastFrameRef?; approvedArtPromptHash?; quoteItemId?; status }.
- AudioPlan { narrationMode:"none"|"device"|"gemini_consent"|"own_file"; voiceProfileId?; musicBedId?; voiceGain0to1; musicGain0to1; narrationSegments:[{textLocalOnly,startMs,endMs}]; ducking:boolean; silenceMs; normalizedOutputLengthMs }.
- CaptionCue { text; startMs; endMs; sourceNarrationSegmentId; visible:boolean; userEdited:boolean }; system state MUST mark changed text/audio/cue stale.
- VideoCostQuote { quoteId; version; projectRevision; projectHash; currency:"USD"|"CAD"; providerName; providerRateCardId; items:[{shotId,modelId,durationSec,resolution,fps,variants,unitRateMinor,subtotalMinor}]; providerCostMinor; expectedAdditionalCostMinor; contingencyMinor; estimatedTotalMinor; customerPriceMinor; maxAuthorizedSpendMinor; fxRateVersion?; expiresAt; signature }.

**Privacy zones:** PRIVATE_USER_CONTEXT = goal, results, raw wish, personal image, real voice, session history; SAFE_ART_BRIEF = client-approved fictional subject/environment/light/camera/exclusions only; RENDER_CONTROL = durations/model/cost/consent. Compiler works local-first, sends to third-party visual provider only **explicitly consented SAFE_ART_BRIEF**; do not rely solely on regex to catch patient data. Build art-only structured allowlist, preview actual outbound request, enforce server-side schema and moderation, audit no PII. Personal photo/voice remain local by default; identity-aware upload is a separately approved product scope.

**49/96/33:** 96 stable IDs never delete/mutate; 49 active contextual IDs in existing registry (Personalization=10, Principal=9, Advanced=11, Pro=13, Extra=6), 47 legacy auto/merged/action/gated. Preserve category IDs PERSONAL/BASIC/ADV/PRO/EXTRA and mapping to display names. Всего 33 внутренних шкал = прежние 30 + embodiment/likeness/morph_strength. Первые вопросы — subject/action/environment/style/format только когда не определены; максимальное число уточнений до сценария 2, третье только при пустом запросе. Manual text > confirmed chip > accepted suggestion > default. EN/RU/ES provide equivalent structured semantics. No inference of clinical diagnosis from video request.

**Источники кадров:** catalog (known rights) → procedural (new deterministic pixels) → approved external AI (new recorded provider bytes). Каждое shot показывает этикетку источника. Для «реалистичный фиолетовый феникс» Local Free сообщает ограничение и предлагает честный symbolic fallback; не обещать, что generative Canvas создал фотоподобную птицу. ## 6. Сценарий, видеорежиссура и качество непрерывности

**Новый поток:** visual idea → local semantic extraction → capabilities check → Style Bible → 4-shot storyboard → shot preview/reference pack → approve shots → free render OR quote for only selected provider shots. Default narrative acts: 1) arrival/establishing, 2) support/development, 3) transformation/possibility, 4) integration/closing. Для длительности >30 сек число shots может расширяться (например 4–8) без ложного обещания, что один файл = 4 уникальные AI-модели. Каждая shot card имеет реальный startMs/endMs, теги источника/лицензии и одобренный art-only English prompt для внешней модели.

**Ключевое качество (не просто adjectives):** одна связанная Style Bible на все кадры; одинаковый fictional hero/silhouette/color/period and lighting continuity. First/last frame служат опорными образами только если реальный image reference asset существует, checksum/rights подтверждены и модель поддерживает его формат. Нельзя выдавать text-only description за реально сгенерированную keyframe-картинку. Не копировать клиентскую фотографию или собственное лицо в художественный reference без специального consent.

**Ручной контроль:** заменить shot, изменить локальную Canvas family, reorder, split, trim, transition, audio cue, оставить исходный одобренный фрагмент; при re-render отправлять только изменённый AI-кадр. Правка shot меняет revision/hash и инвалидирует неиспользованную котировку, но не удаляет/не начисляет повторно уже оплаченную прошлую generation. Сравнение Before/After у конкретной сцены, в том числе рисунок/камера/свет; общий preview и output обязаны использовать один и тот же manifest.

**Pro режиссура:** конкретный subject/action, scale/angle, camera move, depth-of-field, lighting mood, palette grade, shot duration, negative art constraints, model capability badges (реально поддерживается / only prompt guidance / not available). Не передавать фальшивые настройки модели (оптика 85 мм или seed) в payload, если provider API их не поддерживает; такие параметры лишь в художественном текстовом описании и честно отмечены.

## 12. Персональный клиентский контекст, курс 8 видео и Video Therapy

**Upstream:** Psychologist Mind / existing verified test recommendations / client goals → PsychologicalCreativeBrief (purpose, supportive tone, contraindicated motifs, 7-beat emotional arc) → Literary Writer (imagery, strong spoken language, 30–50 reviewed exemplar library) → independent safety/quality editor → Voice Director (pauses/emphasis) → speaker/audio mix → Video Director (safe abstract scenes/AI only if approved). Данные профиля лишь после объяснённого opt-in, источник/свежесть/provenance проверяются в собственном кабинете, не пересылаются видео-провайдеру. Не создавать вторые AI психологические модели в video module и не превращать маркетинговую генерацию в диагностику.

**8 distinct symbolic sessions** уже имеют план (#2507), но не 8 готовых masters; исходные safe motifs: meadow/garden/stream/tree/house/hill/bridge/horizon. Отдельная практическая Session Player архитектура в #2503: помощник сообщает подтверждённый контекст → T0 добровольная краткая оценка → настоящее видео либо честное «пока сценарий» → упражнение/STOP и T1 → прослушивание или текст медитации → T2 и нейтральная рефлексия; это не три клинических теста. Последовательность должна быть доступна без клинических обещаний и без принудительной проработки травмы. Для каждого языка и сессии требовать профессионально проверенный сценарий, реальный audio file + MP4 file, checksum, provider/licensing, проверенную индивидуальную связь с выбранными темами; публикация курса только по фактическому entitlement/готовности. Курс «ОПОРА» и Reiki сохраняют свои базы; не складывать новые 8-session results в Reiki-only schema.

**Стоимость курса:** повторное использование 32 licensed originals и 8 Free families для всей длины; 1–2 paid AI вставки на отдельную сессию по бюджету если нужно, не генерировать 8×10 минут AI-пикселей. Пользователь видит какие материалы готовы, какие требуют дополнительной оплаты и что может скачать/пересмотреть; повторное создание не списывает деньги без quote+consent.

## 13. Privacy, права, клинические и финансовые ограничения

- Гость: scene/idea/profile/photo/voice/files живут в памяти браузера; по умолчанию ни в logs/analytics, ни в Supabase, ни в стороннем AI. Фото загружается только с права/opt-in, EXIF local strip; чужое лицо/голос без права запрещены.
- Пользователь с аккаунтом: opt-in к чтению verified personal tests отдельный от opt-in к сохранению MP4, отдельный от external AI visual prompt, отдельный от публикации. Смена аккаунта A→B очищает запретно разделяемые asset refs; защищённый объект из A не доступен в B.
- Облачный private videos limit: existing MP4 only <=12MB per video, 3 ready videos/client, 36MB/client, 180MB global, 6 attempts/day, только разрешённые темы в API; 50MB bucket cap НЕ отменяет 12MB API cap. Если 30s hybrid не помещается — оптимизация H.264 bitrate, честное скачивание без cloud-save или отдельно согласованное изменение квот; не повышать молча.
- Public publishing только owner-reviewed и rights-cleared; локальное фото клиента не появляется в публичном YouTube. Любая публикация по отдельной кнопке, а не по факту «создано».
- HIPAA/PHIPA/GDPR compliance нельзя автоматически объявлять реализованной. Удаление/TTL, storage retention, deletion, consent versioning, DPA для провайдеров должны быть проверены до чувствительного пользовательского payload.
- Биллинг: нельзя отправить paid POST, если отсутствует provider receipt, право использования, достаточный prepaid balance, owner max cost policy или verified customer entitlement; rate limit per account/day/month. Разные валюта, bonus/purchased ledger и налоги не смешиваются.
- Отказ от гарантий заработка, изменения отношений/здоровья и от заявления о научно доказанной силе «25 кадра». Субтитры/аффирмации прозрачные и добровольные.
