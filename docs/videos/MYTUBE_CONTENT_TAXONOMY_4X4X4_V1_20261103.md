# MyTube taxonomy — version history

This document records the first draft of the MyTube 4×4×4 catalogue. Its original category names and branch assignments have been superseded by the clarified v2 taxonomy.

Use the canonical current structure and category boundaries in `docs/videos/MYTUBE_CONTENT_TAXONOMY_4X4X4_V2_20261103.md` and the current data in `data/video-catalog/mytube-content-taxonomy-4x4x4-v1.json`.

The v2 structure keeps the 4 × 4 × 4 × 4 hierarchy, unique topic IDs, one primary location per topic, RU/EN/ES search-intent metadata, and four editorial scenario concepts per topic. The existing production-connected legacy taxonomy remains unchanged. This catalogue is not published or export-ready until reviewed media bindings exist.
