# MyTube — 1,024 сюжетных варианта (редакционный каталог)

**Дата:** 2026-11-03  
**Статус:** реализация каталога и выборов в коде; НЕ означает опубликованные видеоролики.  
**Иерархия:** 4 категории → 16 подкатегорий → 64 темы → 256 сценариев → **4 независимых сюжета на сценарий (1,024)** → **4 события/эпизода в каждом сюжете (4,096)**.

## Разница между сценарием и сюжетом

**Тема** — исходный запрос пользователя: например, «Предназначение».  
**Сценарий** — конкретная трансформационная концепция внутри темы, например «Чужой компас»: конфликт, смысл и направление изменений; содержит собственную четырёхчастную смысловую схему.  
**Сюжет** — один из *четырёх альтернативных способов* разыграть **тот же сценарий** через события, персонажей, образы и финал, а НЕ один из четырёх этапов сценария.  
**Эпизод** — часть выбранного сюжета; эпизод не равен готовому MP4 и не учитывается как самостоятельный сюжет.

Каждый сюжет имеет уникальный `<scenarioId>-p1..p4`, локализованные RU/EN/ES название, синопсис, четыре события, вектор преобразования, драматургический механизм и состояние `editorial_only_unbound`.

## Четыре разных типа развития истории внутри каждого сценария

1. **История из жизни** (`grounded_dilemma`): обычная ситуация → неожиданное осложнение → собственный выбор → реалистичный результат.
2. **Символическая притча** (`symbolic_quest`): метафорический мир → испытание → ресурс → трансформация пейзажа.
3. **История двух персонажей** (`relational_mirror`): разные реакции на один конфликт → напряжение → диалог и границы → самостоятельное решение.
4. **Развилка и альтернативный финал** (`branching_future`): возможный результат показан первым → возвращение к причине → выбор между продолжениями → открытый финал.

Чтобы не повторять одну и ту же сценическую обстановку на 256 сценариях, внутри каждого типа используются восемь различных окружений / повествовательных приёмов с устойчивым распределением по ID. Сюжеты расширяют **предметные четыре этапа** ранее разработанного сценария; первоисточник смыслового вектора остаётся общим. Это **первый редакционный набор сюжетных черновиков**, который в дальнейшем можно углублять вручную и дополнять медиапривязкой, но он не является 1,024 готовыми анимационными фильмами.

Пример: тема «Предназначение» → сценарий «Чужой компас» → (1) бытовая история реального решения, (2) путь через символический мир, (3) диалог двух персонажей, (4) нелинейная история с альтернативным финалом. Это четыре самостоятельных повествования, каждое со своей последовательностью четырёх эпизодов.

## Архитектура и UX

- `data/video-catalog/mytube-plots-<categoryId>-v1.json` — 4 категориальных источника, по 64 сценария × 4 сюжета каждый.
- `lib/mandala/mytube-scenario-plots.mjs` — метод `listMyTubePlots(scenarioId,locale)`, `getMyTubePlotCount`, `auditMyTubePlots`; только выборочное асинхронное скачивание категории, кэширование загрузки, отсутствие подстановки шаблонного сюжета при ошибке.
- `components/mandala-auto-video-director.tsx` — выбирают **категорию → подкатегорию → тему → сценарий → сюжет**, просматривают 4 события; смена предшествующей ступени сбрасывает выбранный сюжет.
- Старый `recommendMyTubeTopicStoryClips` продолжает подбирать реальные разрешённые клипы на уровне **темы/сценария**. **Совпадение с четырьмя событиями выбранного сюжета не утверждается**. Обязательны действующие проверки источников/прав и явная проверка пользователем.
- Переводы поддерживаются во всех трёх языках. Нет новых генеративных API, оплаты, расхода XP, платных фоновых служб.
- `tests/mytube-1024-plot-variants.test.mjs` тестирует 1,024 ID, четыре разных драматургических режима на сценарий, 4,096 сюжетных эпизодов, RU/EN/ES, отсутствие дублей и безопасность экспорта.

## Границы и следующий шаг

Каталог отвечает за **творческую концепцию**, а не за видеофайлы. Для настоящего производства каждого сюжета нужен отдельный слой `plotId → [licensedSceneIds]` и проверка смыслового совпадения. Только после него можно показывать «сюжет готов к экспорту». Психологически чувствительные темы остаются поддерживающими, добровольными, без обещаний лечения или принудительных переживаний.

LIVE нужно подтверждать отдельно после CI и интеграции PR по цепочке MyTube.
