# Gemini 3.5 Transcribe Live — synthetic-only Free Tier pilot (#5839)

Owner confirmed Free Tier in AI Studio on 28 Nov 2026. Dashboard row shows 3/min, 10K tokens/min, 25/day. These are owner-reported project quotas, not verified deployed key entitlement or session counts.

**Scope:** this is a local test adapter for the dedicated WebSocket STT model, NOT a change to the existing Gemini conversational voice, Whisper runtime, coaching or therapy routes. No API route/client import. No production flag, key, billing setting, deployment, scheduler or automatic cloud retry. Existing batch Gemini candidate #5862 and consolidated runtime PR #5863 remain separate. Google unpaid data terms forbid confidential, sensitive or personal submissions; clinical/medical and regional restrictions also apply. Never use client or owner conversation recordings. Do not expand this pilot into private LIVE based on consent or pricing alone.

## Runbook (Node 22, local espeak and ffmpeg)

1. Use a single designated host and dedicated non-billed Google project. Verify that the dedicated test API key is bound to the Free Tier project, quota is current, billing disabled, and no other tools/agents use this project's STT quota. Never place a key in Git, a client bundle, command-line arguments, logs or PR comments.
2. Run `node --test tests/coach-gemini-live-stt-benchmark.test.mjs` (mock network only).
3. Run `node scripts/coach-speech-gemini-live-benchmark.mjs --synthetic-only --id=ru-short-1 --check-only` (no network). Pick committed RU/EN/ES fixture IDs only. This generates synthetic speech locally from repository references; no arbitrary recordings or texts accepted.
4. Initialize the persistent quota ledger once: `node scripts/coach-speech-gemini-live-benchmark.mjs --init-ledger`. It lives in ~/.local/share/hh-coach-gemini-live-free; never delete/reset it to bypass limits. Exclusive file lock and atomic rename; missing/corrupt ledger, leftover crash files, clock rollback or concurrent lock => fail closed. Single-host operator discipline is required; this is NOT distributed/project-wide enforcement across other hosts.
5. Set HH_GEMINI_LIVE_STT_FREE_CONFIRMED=true, HH_GEMINI_LIVE_STT_SYNTHETIC_ONLY=true, HH_GEMINI_LIVE_STT_EXCLUSIVE_PROJECT=true and provide HH_GEMINI_LIVE_STT_TEST_KEY securely in the local process environment only, after step 1. No existing key/default credential fallback.
6. Run `node scripts/coach-speech-gemini-live-benchmark.mjs --synthetic-only --id=ru-short-1 --output=/secure/ru-short-1.json`. One manually segmented <=15s fixture, one connection, no retry, 30s deadline, final transcript event rather than turnComplete. Repeat with different committed IDs under the ledger. Optional --hints and --vocabulary use only fixed public language/term hints. No automatic CI network execution.
7. Optional local fallback: preinstall faster-whisper and local CTranslate2 Large V3/Turbo model directories outside the repository. Set HH_STT_LOCAL_LARGE_V3_DIR / HH_STT_LOCAL_TURBO_DIR; CPU int8, local_files_only, offline env. On Gemini quota/provider failure, try local Large V3 then Turbo; unavailable weights => no transcript, no paid service. --offline-only compares identical synthesized PCM without Gemini. Model directories and weights are not installed by this PR.

Budget guard reserves each connection attempt before networking (including failed handshakes): 2 starts per rolling minute, 20 per rolling 24h, estimated <=8000 tokens per conservative 90s window. Audio 25 tokens/sec plus 100-token allowance per request, max 15 sec. Real provider accounting/quotas must still be validated; application flags alone cannot guarantee zero billing if the operator supplies a paid project. Stop on provider failure and inspect rather than retrying. The Free Tier is an account constraint, not a request parameter.

Output file contains synthetic transcript only, exact synthesized WAV hash, first interim, end-to-final and total latency, separate primary and fallback results (never attribute fallback to Gemini). This is one-fixture partial evidence, not a full quality benchmark. espeak voice limitations, including RU dictionaries, must be considered. Compare identical audio hashes and critical semantic mistakes, WER/CER and p95 across models; do not mix fallback results or claim measured accuracy without real calls. Existing corpus/scorer format needs an explicit conversion/aggregation step.

Remaining acceptance: verified dedicated key/project binding, successful provider WSS and usage readback, same-audio RU/EN/ES benchmark, production eligibility under applicable privacy and service terms, actual iPhone/live course validation. No private production activation is authorized by this change.
