# Couple instrument source audit (2026-10-20)

All candidate editions below remain research_only and permission_required; no forms, scoring, or live deployment.

- CRSI-32, https://doi.org/10.1111/fare.12590
- CRSI-SP-45, https://doi.org/10.1111/jmft.70181
- CRSI-TR-27, https://doi.org/10.48146/odusobiad.1386206
- CRI-EN-18, https://doi.org/10.1037/pas0000256
- CRI-SG-21 adapted, https://doi.org/10.1007/s12144-025-07728-9
- CRI-ES-14, https://doi.org/10.1007/s41042-025-00240-2
- CRI-IT-14, https://doi.org/10.1007/s11126-026-10253-y
- CRI-PT-14, https://doi.org/10.1024/2673-8627/a000096

The original CRI had 18 items; the European editions test 14 items, the Singapore edition modifies 21. Different forms cannot share unverified scoring. The Turkish CRSI is a shortened 27-item eight-factor adaptation rather than the original 32-item model. Licence and independent respondent-language validation must be checked per edition before software use.
