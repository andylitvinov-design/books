**RU:** Быстрая игровая проверка готовности к фокусу и движению по задачам.

**EN:** A quick playful read on focus readiness and task momentum.

**Important:** Баллы описывают ответы, а не устанавливают диагноз. Скрининговые пороги используются только там, где подтверждены источником. / Scores describe answers, not diagnoses. Screening thresholds are used only where supported by sources.

## Шкалы, наблюдение и добровольная работа / Scales, monitoring and optional practice

Ни одна шкала сама по себе не является «дефектом», который нужно исправить. Выбирайте навык, а не обязательную цель по баллам. / A scale is not a defect to fix; choose an optional skill, not a mandatory target score.

### Режим фокуса — основной показатель / Focus Mode — main score

- **Scale ID:** `summary`
- **Категория / area:** Фокус и внимание / Focus & attention
- **Что наблюдать / what to notice:** Замечайте, какие дела легче начинать и продолжать без отвлечений. / Notice which tasks are easier to start and sustain without distractions.
- **Что можно попробовать / one practical step:** Попробуйте десять минут работы без отвлечений и отметьте, что помогло удержать внимание. / Test one ten-minute distraction-free task and note what helped you stay engaged.
- **Как читать значение / interpreting the score:** Описательное положение в шкале, без придуманной нормы или клинического порога. / Descriptive position in this scale; no invented norms or clinical thresholds.
- **Добровольное направление / optional skill:** Короткие блоки концентрации и реалистичные цели / Small focus blocks and realistic goals
