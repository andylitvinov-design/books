# Больше, чем мои роли / More Than My Roles

**Instrument ID:** `hh-role-freedom` · **Version:** `v1` · **Status:** HH-observation · **Questions:** 6 · **Time:** ~2 min

## Что исследует тест / What this test explores

**RU:** Исследование себя за пределами работы, семьи и ожиданий; без диагностики.

**EN:** Explore identity beyond work, family and expectations, without diagnostic claims.

**Important:** Баллы описывают ответы, а не устанавливают диагноз. Скрининговые пороги используются только там, где подтверждены источником. / Scores describe answers, not diagnoses. Screening thresholds are used only where supported by sources.

## Шкалы, наблюдение и добровольная работа / Scales, monitoring and optional practice

Ни одна шкала сама по себе не является «дефектом», который нужно исправить. Выбирайте навык, а не обязательную цель по баллам. / A scale is not a defect to fix; choose an optional skill, not a mandatory target score.

### Больше, чем мои роли — основной показатель / More Than My Roles — main score

- **Scale ID:** `summary`
- **Категория / area:** Личностные особенности / Personality tendencies
- **Что наблюдать / what to notice:** Отмечайте проявления особенности в разных ситуациях; ни одна черта не является дефектом. / Notice how a tendency shows up in different settings; no trait is inherently a defect.
- **Что можно попробовать / one practical step:** Опишите роль, которая помогает, и один выбор вне этой роли. / Describe a role that serves you and one choice you can make outside that role.
- **Как читать значение / interpreting the score:** Описательное положение в шкале, без придуманной нормы или клинического порога. / Descriptive position in this scale; no invented norms or clinical thresholds.
- **Добровольное направление / optional skill:** Черту не нужно повышать или понижать. / Do not target a personality trait score.
