# Meditation Writer Mind — Skill для небольшой бесплатной модели (v1)

Holistic House · 30 октября 2026 · Исполнительная спецификация с готовым промптом.

Предыдущие материалы: [архитектура двух ролей](./MEDITATION_WRITER_DUAL_INTELLIGENCE_ARCHITECTURE_V1_1_20261030.md) · [Writer PR #2673](https://github.com/andylitvinov-design/books/pull/2673) · [модель и UI PR #2676](https://github.com/andylitvinov-design/books/pull/2676).

## 1. Основная идея

**Нельзя поручать маленькой модели писать сразу всю 10-минутную медитацию.** Вместо этого Psychological/Narrative Director использует существующие проверенные правила Psychologist Mind и готовит 7 смысловых эпизодов. Literary Writer разбивает их на короткие части примерно по 52 слова, формирует короткий System+User prompt на языке клиента, продолжает предыдущий фрагмент по маленькому контексту и собирает единый рассказ. Редактор проверяет каждый фрагмент и весь результат. Две роли — не обязательно две нейросети.

Алгоритм реализован в коде, а не только описан: [small-model-skill.mjs](../../lib/holistic-support/meditation-writer/small-model-skill.mjs).

## 2. Девять этапов

1. Клиент выбирает язык, цель, одну тему, стиль, 5/10/15 минут, необязательную установку и запреты.
2. Сервер проверяет согласие, безопасность и только разрешённый самостоятельный ресурсный мотив (gentle_nature / supportive_object / comfortable_corner / small_light). Запрещённые KIP-мотивы не передаются писателю.
3. Psychological Creative Brief фиксирует 7 эпизодов: прибытие, выбор, образ, раскрытие, собственный небольшой выбор, возвращение, завершение.
4. Выбирается один стиль: gentle_simple, grounded_practical, poetic_contained, contemplative.
5. Каждый эпизод разбивается на малые фрагменты примерно по 52 слова, подходящие для модели с коротким лимитом вывода.
6. Следующей части передаётся лишь последняя принятая короткая фраза, а не весь профиль или история клиента.
7. После каждого фрагмента независимый валидатор проверяет длительность, язык, нежелательные темы и опасные инструкции. Небезопасный результат сразу отвергается, для технически некорректного ответа допустима одна повторная попытка.
8. Из частей собирается один сценарий; существующий Writer/Editor проверяет общий ритм и ограничения, возвращает текстовый draft с честной оценкой длительности.
9. Озвучка и MP3 — отдельный этап после явного одобрения сценария; текст не считается готовым аудио.

## 3. Готовый System prompt (русский)

> Ты автор оригинальных мягких ресурсных медитаций. Напиши ОДИН небольшой литературный фрагмент для спокойного чтения вслух. Практика добровольная, это НЕ лечение. Используй один центральный образ, короткие естественные предложения и одну-две мягкие сенсорные детали. Не ставь диагнозы, не трактуй символы за слушателя, не обещай исцеления, денег или обязательного результата. Не требуй управлять дыханием, закрывать глаза, возвращаться к травме, прикасаться к телу или чувствовать определённую эмоцию. Можно остановиться или ничего не представлять. Верни один абзац оригинальной прозы без заголовков, списков и пояснений.

## 4. Готовый User prompt для одного короткого фрагмента

> Напиши эпизод 3 из 7 персональной ресурсной медитации. Это только один короткий фрагмент, НЕ вся медитация.
>
> Цель: возможность выбора и внутренняя опора.
>
> Разрешённый сюжет: спокойное место на природе. Дополнительный выбранный символ: дерево, без обязательной трактовки.
>
> Стиль: спокойная поэтичная проза, без пафоса; короткие и средние предложения.
>
> Длина: 45–55 слов.
>
> Эпизод: мягко представить центральный образ и одну деталь света или движения.
>
> Запреты: не контролировать дыхание, не требовать закрыть глаза, никаких клинических техник или гарантий результата.
>
> Предыдущее предложение: «Можно прислушаться к тому, что сейчас находится вокруг».
>
> Необязательная фраза клиента: «Я могу выбирать свой ответ». Передавай смысл мягко, не повторяй установку механически.
>
> Верни только художественный текст одним абзацем. Не вводи новый пейзаж, персонажей или объяснение значения символа.

Это готовый ручной пример. Для реальных клиентских запросов сценарий разрешается на сервере; prompt компилируется автоматически из безопасных кодов. Не отправлять в бесплатную внешнюю модель клиентскую историю, диагнозы, результаты тестов или личные фразы без соответствующей правовой и технической проверки.

## 5. Реальный программный контракт

Функции:
- compileSmallModelPrompt: строит System и User prompt RU/EN/ES из разрешённого brief, beat, номера части и короткого предыдущего текста; клиентская фраза выключена по умолчанию.
- splitSmallModelBeat: распределяет количество фрагментов исходя из бюджета слов.
- createSmallModelBeatWriter: принимает любой генератор текста как функцию, последовательно вызывает его, проверяет каждую часть, собирает текст, совместим с уже существующим writeMeditationDraft.
- createOwnedSmallModelWriterProvider: связывает этот skill с существующим server-only Ollama adapter, не раскрывая токены браузеру.

Пример серверного вызова **после** подготовленного Psychologist Mind и подтверждённого consent:

    import { writeMeditationDraft } from "./lib/holistic-support/meditation-writer/writer.mjs";
    import { createOwnedSmallModelWriterProvider } from "./lib/holistic-support/meditation-writer/owned-writer.mjs";

    if (prepared.status !== "brief_ready") throw Error("NOT_ELIGIBLE");
    const writeBeat = createOwnedSmallModelWriterProvider({
      endpoint: process.env.HH_AGENT_OLLAMA_ENDPOINT,
      model: process.env.HH_AGENT_OLLAMA_MODEL,
      bearerToken: process.env.HH_AGENT_OLLAMA_TOKEN,
      allowPersonalPhrase: false
    });
    const draft = await writeMeditationDraft(prepared, { writeBeat });
    // draft.status = draft_review_required только если все проверки пройдены.

**Не запускать много последовательных модельных запросов в одном коротком Vercel HTTP request.** Для живой длительной генерации нужен отдельный worker/очередь с отменой и квотами.

## 6. Кандидаты бесплатных локальных моделей

- [Qwen3 0.6B](https://ollama.com/library/qwen3/tags): около 523 MB на диске. Самая лёгкая проверка; художественное качество может быть ограничено.
- [Qwen3 1.7B](https://ollama.com/library/qwen3/tags): около 1.4 GB на диске; рекомендую начать с неё и измерить RU/EN/ES качество.
- [Qwen3 4B Instruct](https://ollama.com/library/qwen3/tags): около 2.5 GB на диске; стоит сравнить со слабой моделью на тех же запросах.

Команда на собственном устройстве с Ollama: ollama pull qwen3:1.7b. Размер модели на диске не равен полной потребности в RAM/GPU. Публичный доступ к Ollama запрещён; использовать только защищённый серверный gateway. Бесплатный локальный inference не означает отсутствие затрат на оборудование и электричество.

Отдельный Gemini free-tier режим уже появляется в PR #2676, но он может обрабатывать **только анонимные коды**, не приватную психологическую историю. Он отличается от собственного локального Writer.

## 7. Проверки и границы готовности

Автоматические тесты: RU/EN/ES, 7 эпизодов, 4 стиля, согласие/отказ, запрещённые KIP мотивы, короткий/опасный модельный ответ, одна техническая повторная попытка, отсутствие утечки клиентской фразы по умолчанию, нулевые фиктивные audioAssetId.

Независимый редактор должен оценить: один сквозной образ, плавные переходы, устный ритм, литературную оригинальность, отсутствие внушений, безопасность и фактическую длину после TTS. Размер текста 10 минут нельзя подтвердить только словесным бюджетом: при реальной озвучке потребуется измерение.

**Статус:** pure code + mock-tested integrations; нет подтверждённого постоянно включённого локального inference host, готового MP3, очереди задач или production rollout. Следующий этап — практическое A/B на локальных Qwen 0.6B, 1.7B, 4B, затем durable worker и редакторская приёмка.
