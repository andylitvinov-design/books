# Holistic Intelligence — Psychologist Practice Engine / v1.1

**29.10.2026. Исходный код и тесты в ветке PR #2532.** Это локальный модуль принятия решений и подготовки контента, а не автоматически опубликованный терапевтический продукт. Текст написан для разработчиков, редакторов контента и клинических рецензентов.

## Задача

Расширить `Psychologist Mind` двумя практическими возможностями:
1. Выбрать **один из шести форматов восьмисессионного видеокурса**, построить оптимизированную последовательность целей и упражнений и подготовить 8 видеосценариев по 12 минут (структурные заготовки, а не готовые видеоролики).
2. Использовать **каталог мотивов символдрамы / KIP и открытых символов** для подготовки персональных **оригинальных ресурсных медитаций** на RU, EN, ES по запросу клиента — с добровольным выбором мотива, акцента, символа и длительности. Классическая KIP-психотерапия и работа с глубокими конфликтами остаются только для специалиста.

Модули:
- `lib/holistic-support/psychologist-mind.mjs` — preflight, 5P, диалог, маршрутизация задач;
- `lib/holistic-support/psychologist-video-curricula.mjs` — модели курсов, 12 практических навыков, план 8 видео;
- `lib/holistic-support/kip-symbol-registry.mjs` — 41 мотив, 63 символа, источники и ограничения;
- `lib/holistic-support/psychologist-meditation-composer.mjs` — оригинальный сценарий медитации, вариации, паузы;
- `tests/psychologist-practice-engine.test.mjs` — контрактные сценарии и защита.

## Методические источники и границы переноса

- DGKIP: https://www.dgkip.de/curricula — уровни мотивов: ресурсные (Blume, Baum, Wiese, Bach, Quelle), отношения (Haus, Berg, Waldrand, Baumgruppe, Tierfamilie), регрессия и продвинутые конфликтные сюжеты. Это описание **профессионального** обучения, не лицензия на авто-терапию.
- ISKIP: https://igkip.org/en/what-is-kip/ — KIP как диалоговая психодинамическая психотерапия, мотив индивидуален, его ход задаёт клиент. Значения символов не фиксированы.
- NICE NG222: https://www.nice.org.uk/guidance/ng222/chapter/recommendations — guided self-help CBT/BA может иметь 6–8 структурированных встреч, обычно при участии обученного специалиста; это не обоснование универсальных 8 сеансов для всех.
- NICE CG113: https://www.nice.org.uk/guidance/cg113/chapter/recommendations — структурированная помощь при тревоге, обычно с поддержкой специалиста.
- WHO 2020: https://www.who.int/publications/i/item/9789240003927 — практические низкоинтенсивные навыки: заземление, дистанцирование от мыслей, ценности, принятие, доброта.
- WHO 2026: https://www.who.int/publications/i/item/9789240120785 — руководство по внедрению индивидуальных психологических программ самопомощи в разных форматах.
- SAMHSA: https://www.samhsa.gov/mental-health/trauma-violence/trauma-informed-approaches-programs — безопасность, прозрачность, сотрудничество, право выбора, предотвращение повторной травматизации.

**Мы не копируем** длинные сценарии, мануалы или тексты упражнений из учебников/программ. Здесь только проверяемые короткие методологические указатели и оригинальные сценарии. Клиническая эффективность собственных курсов Holistic House не установлена.

## Шесть доступных моделей курса

| ID | Название | Ключевые навыки и логика |
|---|---|---|
| `stress_foundations` | Стресс: 8 шагов устойчивости | цель → ориентация → реакции → ресурсы → мысли → эксперимент → выбор → итоги |
| `anxiety_cbt` | Навыки при тревожности | цель → ориентация → триггеры → мысли → маленькое действие → выбор → поддержка → итоги |
| `relationship_skills` | Отношения и границы | цель → ресурсы → повторение → границы → самоподдержка → эксперимент → выбор → итоги |
| `self_worth` | Самооценка и бережность | цель → поддержка → реакция → необязательный образ → мысли → ценности → действие → итоги |
| `meaning_and_values` | Ценности и направление | цель → ценности → ресурсы → выбор → препятствия → действие → перенос → итоги |
| `imagery_resources` | Мягкие образы и опора | цель → ресурсы → ориентация → образ → доброта → действие → выбор → итоги |

Последний формат доступен **только после отдельного согласия на имагинацию** и если другие ограничения не запрещают метод. Восемь занятий — продуктовый формат для низкоинтенсивного обучения навыкам, не курс лечения ПТСР. Для эмоционально сложных случаев генератор возвращает передачу специалисту.

**Выбор оптимальной последовательности:** 1) проверка риска; 2) явный выбор совместимого формата клиентом; 3) при запросе про тревогу выбор `anxiety_cbt`; 4) иначе маршрут по подтверждённой теме: стресс/отношения/самооценка/смысл. Метод каждой сессии выбирается только из проверенного закрытого реестра, с учётом запретов `avoidMethods`, согласий и отсутствия противопоказаний. Алгоритм одинаково применяется к программе и к видео, чтобы беседа не расходилась с занятиями.

## 12 практических навыков

`goal_contract`, `present_orientation`, `resource_inventory`,
`map_trigger_response`, `values_clarification`, `thought_reflection`,
`self_compassion`, `boundary_rehearsal`, `small_behavior_experiment`,
`mindful_choice`, `resource_imagery`, `progress_review`.

Каждый содержит **RU/EN/ES название, 3 шага выполнения, исходную методологическую ссылку, цель, запрет автоматического запуска**. Это psychoeducational micro-skills, не лицензированная психотерапия или самостоятельная клиническая процедура.

**Контракт каждого видео:** 720 секунд, 6 блоков: приветствие (60 с), T0 (90), инструкция навыка (150), опциональная практика (270), T1/рефлексия (100), перенос в жизнь (50). Видеосценарий — структурированные `segments[]` с `narration` и `onScreen`; функции рендера, TTS, asset upload и публикация в этой версии НЕ подключены. На реальном сайте нельзя обещать воспроизведение, пока `videoAssetId` и publication gate не подтверждены.

## Библиотека символдрамы

Реестр включает:
- **5 классических базовых мотивов:** луг, ручей, гора, дом, опушка леса.
- Ресурсные и отношения: цветок, дерево, источник, место комфорта, группа деревьев, семья животных, помогающий образ и др.
- Клинические темы регрессии и более глубоких мотивов: животное с детёнышем, фигуры из детства, лев, розовый куст, экипаж, ночной сон, пещера, болотная яма, вулкан, подземный мир и др.
- Психосоматические и смежные мотивы, поименованные отдельно: тёплый источник, облако, внутреннее пространство тела, мост, дверь, дорога и пр.
- **4 собственных оригинальных низкоинтенсивных ресурсных сюжета:** `gentle_nature`, `supportive_object`, `comfortable_corner`, `small_light`.

**Важно:** 41 мотив — широкий начальный реестр, а не буквальная энциклопедия «всех» возможных KIP-мотивов. Некоторые позиции — смежные темы отдельных школ, а не обязательные канонические мотивы KIP; у каждой есть `tier` и `sourceUrl`. Полный курс обучения KIP нельзя заменить такой таблицей.

**Словарь 63 символов** (вода, деревья, корни, путь, мост, дверь, животные, свет, зеркало и т.д.) хранит только темы для свободного исследования (`explorationThemes`) и вопрос клиенту. **Никаких утверждений типа «волк = отец», «вода = бессознательное» или скрытых диагнозов.** По умолчанию символ самостоятельно означает только то, что клиент сам с ним связывает.

Все классические KIP-мотивы: `selfGuided=false`, `clinicalReviewRequired=true`.
Только 4 оригинальных, явно помеченных `origin=original_nonclinical_resourcing`, можно использовать для необязательных самостоятельных ресурсных медитаций. Автоматические медитации допускают лишь ограниченные явно выбранные нейтральные символы (дерево, цветок, солнце, камень, облако, свет, семя, сад), не навязывая им интерпретации. Другие символы направляются на пересмотр.

## Построение персональной медитации

Входы: проверенный фокус, текущая безопасная сессия, `consent.resourceImagery=true`,
`intent.intentionCode` или распознанная тема запроса, `intent.motifId`,
`intent.symbolId`, длительность 5–15 минут, предпочтения (`style`,
`channel`, `avoidElements`, `noImagery`) и язык RU/EN/ES.

Шаги:
1. Из общего `buildPsychologyProgram` получить статус. При urgent, травма-обработке, ухудшении, несовершеннолетии и других клинических ограничениях остановить самостоятельное создание.
2. Отдельное согласие на образ; проверить запреты и сохранённое пожелание не делать образные упражнения.
3. Выбрать явный **безопасный ресурсный мотив**; если мотив клинический — возвратить `clinician_review_required`, **не подменять его другим молча**.
4. Определить тему по явному `intentionCode`, иначе по ограниченным ключевым признакам новой реплики, иначе по фокусу программы; не копировать сырой текст в сценарий.
5. Необязательный нейтральный символ по явному `symbolId`; избегать готовых трактовок.
6. Собрать 7 оригинальных текстовых блоков: прибытие → выбор → ресурсный образ → свободное исследование → небольшой шаг поддержки → возвращение в настоящее → завершение.
7. Рассчитать паузы для общей длительности, не принуждая к дыхательным упражнениям, закрытию глаз или визуализации.
8. Вернуть `script`, `segments`, `plannedDurationSeconds`, `title`, `motifId`, `symbolId`, но `rendered=false`, `published=false`, без несуществующих media asset IDs.

Это настоящий локальный генератор **текста** по контролируемым параметрам и распознанной теме запроса, **без внешнего LLM API**. Он ещё не пишет литературно неповторимый текст по произвольному длинному описанию клиента. Следующий отдельный этап — редакторский LLM adapter, который может только перефразировать проверенные блоки по одобренному structured contract, но не обходить безопасность и не предлагать диагнозов.

## API-контракты и вызов в основном агенте

Один вход `consultPsychologistMind()`, новые задачи:

```js
import { consultPsychologistMind } from "./lib/holistic-support/holistic-intelligence.mjs";
// NOTE: safety/access must be established by trusted server. Do NOT accept
// ownerScoped, verifiedPractitioner or safety=clear from raw browser JSON.
const scope = { safety: trustedSafetyPreflightResult,
                access: trustedAuthenticatedOwnership,
                consent: serverVerifiedConsents };
const options = consultPsychologistMind({task:"course_options",locale:"ru",
  intent:{focus:"stress"},...scope});
const video = consultPsychologistMind({task:"video_course",locale:"ru",
  intent:{focus:"stress",courseId:"anxiety_cbt",rawUtterance:"Беспокоит тревожность"},
  ...scope});
const meditation = consultPsychologistMind({task:"meditation",locale:"ru",
  intent:{focus:"stress",intentionCode:"clarity",durationMinutes:10,
          motifId:"small_light",symbolId:"tree"},
  ...scope}); // scope.consent.resourceImagery must already be server-verified
const motifs = consultPsychologistMind({task:"kip_library",locale:"ru",
  intent:{focus:"stress",selfGuidedOnly:true},...scope});
const symbol = consultPsychologistMind({task:"symbol_explore",locale:"ru",
  intent:{focus:"stress",symbolId:"bridge"},...scope});
const turn = consultPsychologistMind({task:"dialogue",locale:"ru",
  state:{sessionNumber:2,phase:"practice_intro"},
  intent:{focus:"stress",courseId:"anxiety_cbt"},...scope});
```

Внутри диалога `skillPreview` имеет ровно 3 коротких шага и `needsExplicitStart=true`. Он не запускает воспроизведение сам.

## Обязательные проверки перед live

1. Server-side auth/owner scope; раздельные согласия на тесты, память и имагинацию; отказ от хранения сырого текста и журналов с PII; отмена согласия.
2. Безопасность: клинические и травматические запросы → human review; никаких самостоятельных KIP, EMDR, CPT, PE или попыток извлекать воспоминания.
3. Клиническая редактура каждой сессии и медитации; отдельный контент-gate и при необходимости проверка специалистом; тексты не должны обещать излечение.
4. Наличие лицензированных/собственных видеоматериалов и аудиотреков, сохранённые IDs, права, публикация, длительность, RU/EN/ES voiceover.
5. Визуальная и техническая доступность: captions, reduced motion, возможность пропуска и паузы, крупные мобильные элементы, T0/T1 только добровольно.
6. Е2Е (аккаунт A/B, ошибочный consent, контент 320/390/430, отказ от внешнего LLM, отсутствие PII в network/telemetry), полный CI и контроль exact-head SHA.

**Реализовано сейчас:** реестр, алгоритм выбора, текстовый сценарий медитации, структурные сценарии 8 видео, интеграция в общий pure engine, типы, контрактные тесты.  
**НЕ сделано:** server API, client UI, реальный рендер видео, TTS, публикация, проверка клиническим специалистом, live-выкатка. Не выдавать черновик за запущенный курс.
