# Daybook tap-first practical exercises — owner approved 2026-11-26
Reusable standard for Clarity, Goal, Business, Reiki and future courses. One screen = one action. 1–3 minute mini-games, 4 action screens + explicit review (45 screens in first course). Big tap targets, cream/brown, progress dots, visual scales, icon cards, collections of up to three, no mandatory typing, no right/wrong or penalties for subjective responses. Use actual practices (notice support, natural breathing, use a resource, select an action), with skip and stop choices where needed. Preserve original private notes and never reinterpret them as completion. Persist via existing owner-scoped verified journal saver; confirm only after receipt, retry same operation, duplicate fail closed. Progress per game, 3 per day. No new XP balance or grants; use canonical XP ledger only after integration and idempotency tests. Never silently share private answers or infer clinical diagnoses. Coach-confirmed answers require a verified, consented mapping before prefill. Coach homework only from authoritative timed ending, never disconnect. Goal draft must be reviewed and created through existing canonical Goal Builder; do not pretend a journal result is a profile goal. Existing canonical vectors link stays available; game needs and self-ratings are independent self-reports, not canonical axis IDs.
Day 1: life balance, inner world, needs. Day 2: energy battery, resource collection, moment of calm. Day 3: direction, goal draft, first quest. RU/EN/ES. Future courses reuse schema and renderer with own versioned tags. Acceptance: signed-in 320–430px, all choices, back, stop, no false completion, verified reload, duplicate and account change, all locales, canonical goal continuation, protected CI and production SHA. No new provider, manual deployment or paid resources.

## Visual practical feedback
Action screens with a suggested duration provide optional 30/60-second local timers, pause, restart and pause on backgrounding. Timer expiry never claims completion. Preserve explicit finished, stopped and later responses. Review and verified saved results show visual scale bars, selected resource chips, a four-domain self-rated balance wheel and before/after comfort ratings; old text remains readable if it cannot round-trip exactly. Explicit client-initiated clipboard export only; no automatic coach disclosure. Do not confuse the four-domain game wheel with the canonical eight-axis coaching report.
