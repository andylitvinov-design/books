## Data rules

- **Google columns:** owner-exported GBP Performance for the stated date range. Keep raw query rows outside public Git if they contain account-private information.
- **Website columns:** consented aggregate analytics only. Do not store names, emails, test answers, scores, report text or health-like data in event payloads.
- **Business columns:** only real, legitimately available CRM/accounting records. `Qualified` means a human-reviewed enquiry that matches the offer; `Booked` means a real appointment is reserved; `Paid` means payment is actually recorded.
- **Primary KPI:** qualified paid clients. Use supporting metrics to diagnose the funnel, not to claim commercial outcomes.
