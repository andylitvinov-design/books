## Visual rules

- A4 portrait.
- Prefer one page whenever the content fits.
- Clean white background and large margins.
- Small understated lighthouse illustration at top-left.
- Name and credentials to the right of the lighthouse.
- Restrained gray/blue typography; no dramatic beams, waves, halo, gradients, cards, dashboard UI, or decorative borders.
- Thin light-gray divider below the letterhead.
- Main text around 10–11 pt with discreet headings.
- Signature block in the lower half with practitioner name, credentials, address, and phone.
- The document must look like a simple professional private-practice document, not a marketing brochure.

## Generation rules

1. Generate **Receipt / Invoice** and **Homeopathic Recommendation** as separate documents.
2. Never put payment/price information into the Homeopathic Recommendation.
3. Never put remedy instructions into the Receipt/Invoice.
4. Clinical fields are practitioner-entered. Do not invent remedy indications, potency, dosage, frequency, duration, or instructions.
5. In the web client view, linked remedy names must resolve to the canonical RU/EN remedy pages; preserve hyperlinks in the PDF when technically supported.
6. Keep the lighthouse letterhead identical across Receipt, Invoice, and Homeopathic Recommendation.
7. Prefer one-page output. Additional pages are allowed only when longer recommendations require them.
8. PDFs must be clean A4 and suitable for download, print, or insurance submission.
9. Client-facing documents must never expose admin IDs, selectors, tokens, storage fields, Redis details, or internal notes.
10. Do not commit real client documents or patient data to the repository. Use synthetic fixtures only.
