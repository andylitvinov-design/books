# My Coach — Signature Speech v1 / Personality Dialogue 3.0
Owner request 26 Nov 2026; existing parent #5697, continuation of #5702/#5705.
Each public coach has an original register of supportive and inspiring expressions: 8 contexts × 2 variants × 8 coaches × 3 locales (128 distinct authored semantic lines, 384 localized variants). The shared immutable library is exposed by both editorial and runtime passports. Hidden legacy identities retain prior behavior.

## Intent
Mira: care, support, pace. Max: initiative and learning without pressure. Sofia: needs, dignity and boundaries. Alex: evidence and feasible choices. Merlin: values and perspective. Harry: realistic courage and real support. Genie: wishes and possibilities grounded in reality. Caesar: agency, choice and responsibility without dominance.

Contexts: support for explicit distress, uncertainty/reduced scope, listening/refusal, inspiration in allowed exploration, recognition of explicitly reported positive feeling (not a claim of success), action-oriented support, review and close. No script on direct answer, correction, social turn or routine question-streak reflection. A phrase is a style example, never an automatic answer or new question, action, diagnosis, promise, evidence, consent, or confirmed result. Do not force optimism, infer progress, add slogans to every question, or copy phrases unrelated to the current client's words.

Text Director chooses one eligible fixed editorial cue using its existing authorized move and explicit self-report signals. Recent assistant turns are consulted ephemerally (bounded window; no new retention) to suppress verbatim repeats, including punctuation/case variants; if both choices are exhausted, omit the reference. Existing fictional examples remain available for non-signature stages. Existing Gemini shared setup receives two compact style anchors; Live checkpoint appends a complete localized cue only after mandatory content and existing delivery guidance fit, within the existing 620-character cap. Suppress the new cue during incomplete opening. No new provider request or persistent state. This is not a guarantee the model will use a cue or never paraphrase it similarly.

## Acceptance
Native regression imported into existing coaching test suite. Tests cover language completeness, distinctness, immutable shared passports, hidden IDs, repeat/exhaustion, untrusted cue substitution, all eight personas across contexts, explicit positive/negative signals, no-advice/answer/correction, preservation of mandatory Live text/620-character cap and opening consent. Actual provider, authenticated mobile and blind dialogue acceptance remain required; source tests alone are not LIVE proof. No new workflow, model, database, provider calls, paid service, media, or manual deployment.
