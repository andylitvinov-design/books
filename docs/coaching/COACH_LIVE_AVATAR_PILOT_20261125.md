## Release gates
1. Obtain separate free accounts, verify rights to approved avatar image, no auto-charge, free cap. Simli template test only; do not upload Mira on a paid plan. Sequencer create/prepare may itself incur cost: do not call until confirmed free. Review privacy and retention; Simli's public terms allow broad use of submitted content and Enterprise advertises ZDR; do not send actual coaching audio without review/approval.
2. Install reviewed simli-client@3.2.0 through normal npm install --save-exact and commit generated integrity-bearing lockfile; wire SDK to the injected adapter and enable only the admin route with strict testing. No remote runtime CDN imports. Verify actual Simli token response and stop/interrupt. Test Sequencer returned audio and video on iPhone, correct stop/timeout including pending startup, no duplicate audio; inspect provider usage. Test one provider at a time.
3. After tests, integrate renderer with the existing GeminiLivePcmPlayer at its scheduled output node (not microphone). Simli expects mono PCM16 16 kHz; Gemini output is 24 kHz, use streaming resampler maintaining frame state. Sequencer publish a Web Audio destination track from the existing speech output. Returned audio becomes sole speaker output, preserving echo reference with actual playback delay. On interruption clear Simli buffer; Sequencer stop queued input and verify remote buffer handling. Stop video on pause, navigation, hidden tab, end or failure; keep Gemini's logical dialogue, token/session resumption and encrypted protocol unaffected. No fallback to another paid provider automatically; fallback is Classic Avatar. Do not replace current coach visuals before verifying identity, gestures and latency.
4. Paid launch requires separate approval, commercial terms and retention review, per-provider budget ceilings, durable server-side idempotent payment/entitlement and week quota (not client state), one session per entitlement, verified max 1200 s, reconciliation of errors/reconnects and refunds. Keep product disabled until verified real full cost including Gemini, payment fees and actual vendor plan. No client health or private context exported without explicit informed consent. No new manual deployment; use protected merge and existing budget-capped publisher only.
