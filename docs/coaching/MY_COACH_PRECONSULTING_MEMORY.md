# My Coach · Preconsulting and intelligent missing-data interview
Owner request 26 Nov 2026. Common contract for all personas and coaching programs (RU/EN/ES).
1. Greeting remains separate. With permission, show the real memory lookup in progress, then confirm preferred name and explicitly recall the last reviewed topic. Offer previous/new; never claim a lookup succeeded if it failed or was declined.
2. Use the existing owner-scoped encrypted archive, staged memory ticket, provider-specific consent and selected profile/goal/test grants. Never export the complete account, raw transcripts or unreviewed hypotheses. A new topic or revoked consent suppresses historical context; corrections supersede earlier statements.
3. After the client chooses continuation, derive an advisory from the latest reviewed protocol: confirmed, candidate needing review, not recorded, skipped, and whether the outcome of a previously agreed step should be checked. Not recorded does not mean absent; a planned step does not imply unfinished. Current session and stage evidence remain separate.
4. Provider prompt: analyze relevant available profile, prior protocol and current turns before selecting one missing detail. Do not repeat known information; confirm changed, inconsistent or stale details briefly. Example: known symptom description and intensity; ask only relevant onset, frequency or circumstances. Coaching does not diagnose or replace clinical assessment.
5. Only explicit readiness starts the existing coaching timer. Opening, memory retrieval and recap do not consume coaching time. Previous answers cannot automatically close current stage or create consent, diagnosis or homework.
6. Continue using existing reviewed protocol and two-stage confirmation flows; no new data store, new model request, provider or subscription.
Release acceptance: protected CI, signed-in mobile Basic and Pro for returning/new/declined/failure/changed-topic accounts; verify no cross-account/provider leakage and no timer before consent. Scope of this patch is archived reviewed sessions and existing approved profile projection; unfinished live draft handoff, automatic durable consent/preferences and per-field semantic ledger across arbitrary historic sessions require separate integration and real device acceptance. Do not claim those are implemented here.
