# My Coach P0 — Pause and continue the same session (26 Nov 2026)

Owner decision: Groq Basic and Gemini Pro must allow an explicit pause without finishing the logical course session, losing already used or unused minutes, resetting protocol or repeating the greeting. A pause, hidden page or lost connection must not assign homework, start a new session or grant another daily allowance.

## This patch (mounted document)
- Both transports expose Pause; resume requires a gesture. Basic cancels capture, pending model/audio and retries, retains visible transcript and incomplete client turn, and restarts listening without another introduction.
- Shared active presentation clock samples partial intervals at pause, ignores paused time and restores existing private draft duration. Uses existing consented encrypted draft queue only; no raw audio storage, new provider, new services or grant.
- Gemini uses the existing provider resumption checkpoint, original credential and explicit unavailable fallback. Provider-issued expiry, reconnect limits and already accepted/in-flight token usage are not overridden. A held socket may finish a previously submitted turn; the patch does not guarantee zero vendor token use for such a turn.
- Text continuation after an unavailable Gemini credential is explicit and local, not an automatic paid fallback.

## Remaining P0 — durable, server-authoritative restoration
Coordinate with #5701 canonical cumulative logical clock and #5714 Basic duplex transport. No parallel quota ledger or production flag changes. At consented start/resume acquire one account/course/session lease with idempotency key; at pause or observed disconnect atomically settle last verified connected interval and revoke the transport lease. Reuse same session/protocol ID, revision, confirmed answer provenance, outstanding question, and same grant balance. No new provider request while parked; cancel/invalidate stale generation, STT, TTS and director callbacks. Store only owner-authorized encrypted text/protocol checkpoint; never persist provider credential or raw audio. After expiry a new technical credential must be issued only on explicit resume and within the existing logical grant's unused balance, with no second daily-session consumption, and prior approved context restored; if unsupported, present explicit same-session text fallback. Do not pretend provider TTL freezes or previously consumed tokens are refunded. For offline/closed app resume the server last observed active time, not wall time. No context transfer without consent. Existing protocol review must remain intact; unresolved answers remain unconfirmed.
