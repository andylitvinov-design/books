# Owner decision: six fixed stage bars · 26 Nov 2026
All My Coach entry points use six positions, not a variable count. Clarity Day 1: Contact & continuity / Situation & state / Balance (method consent, measurements, analysis, verification) / Needs / Support / Integration. Verification remains a distinct protocol checkpoint and time window; it is not a seventh horizontal bar. Other courses keep their actual method questions inside the six positions. Empty positions remain grey and do not introduce fake questions.
Whole-bar color: grey = no recorded response; soft yellow = some recorded or unresolved/skipped items, including fully captured but not verified; green = every assigned actual field has recorded and verified client evidence. A new prompt, active stage, clock, model speech, interruption or unknown value never turns a bar green. Explicit skip remains distinct; correction reopens its field. The current outline is neutral. The existing per-field captured/verified marks remain separate; current-session evidence is not proof of durable archive save.
Scope: shared UI projection, not activation of Clarity v5 server ledger. Legacy courses with fewer thematic fields have unconfigured grey slots until their protocol is expanded. Pending #5701 owns versioned consent, current-only ratings, restoration and time authority. No new spend, provider, migration or manual deployment.
