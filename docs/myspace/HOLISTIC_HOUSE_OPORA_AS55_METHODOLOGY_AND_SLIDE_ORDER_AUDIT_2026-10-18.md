# ОПОРА AS-5.5 — методический аудит 15 экранов × 14 дней

**Дата:** 18 октября 2026. **Статус:** реализованная новая редакция для **новых циклов AS2**, version ID `hh-antistress-skills-v7-20261018`. Старая AS-5.4 (`v6`) и V3/V5 сохраняются только для уже начатых прохождений; данные не перезаписываются. Самостоятельная образовательная программа, не лечение PTSD, травматических или иных психических расстройств.

## 1. Зачем проверяли повторно

Аудит фактического кода AS-5.4 обнаружил четыре повтора/риска:

1. **Экран 11:** три варианта ответа из упражнения зачастую совпадали с экраном 9, а ответ вызывал одинаковую общую реакцию — это не проверяло перенос обучения на новый случай.
2. **Экран 12:** выбор плана дублировал действия с экрана 9 без ясной связи **«если событие → возможный шаг; если не подходит → запас»**.
3. **Подсказки:** одна общая подсказка показывалась на нескольких принципиально разных этапах, не объясняя конкретного следующего действия.
4. **Честность попытки:** «Не пробовал(а)» или «Некомфортно» нельзя было выбрать до клика по действию, которого человек не выполнял. При просмотре слайда нельзя приписывать навыку успешность.

## 2. Итоговые роли пятнадцати экранов

| № | Роль | Проверяемое действие и качество |
|---:|---|---|
| 1 | Приветствие | Участник видит **одну достижимую микроцель**, открывает урок без требования особого самочувствия |
| 2 | Необязательное «сейчас» | Можно отметить **моментную доступность навыка** 0–10 или продолжить без ответа; не диагноз |
| 3 | Темп | Обычный / короткий / чтение; не повторять здесь выбор конкретной телесной опоры |
| 4 | Фокус | Обозначить, **для чего** изучается действие сегодня; допускается общий фокус без теста |
| 5 | Афоризм | Одна оригинальная установка; **откликается / сомневаюсь / не согласен**. Нет правильного убеждения и ответа «Пропустить» |
| 6 | Модель / показ | Нейтральный реалистичный пример «ситуация → шаг → возможная поддержка», без обращения к травматической памяти |
| 7 | Подготовка | Выбор безопасного варианта текущего упражнения (не дублирует общий темп), естественное дыхание, стоп |
| 8 | **Замечаю** | Распознать ключевой элемент через отдельный **обучающий кейс**, получить корректирующий отклик по каждому варианту |
| 9 | **Пробую** | Выбрать конкретную микрооперацию, по желанию действительно её попробовать; после — честно ответить о попытке |
| 10 | **Повторяю** | Вспомнить действие с меньшей подсказкой. Подсказка остаётся доступной, за неё нет штрафа |
| 11 | **Новый кейс** | Принципиально **новая ситуация**; три варианта, **три адресные реакции** (включая спокойное пояснение неточной классификации) |
| 12 | **Перенос в быт** | Отдельные 3 правила **«если … то …»**, не повторяют экран 9; явная необязательная запасная опора |
| 13 | Рефлексия | Подошло / частично / без изменений / неудобно; добровольный *тот же* 0–10 вопрос с экрана 2 |
| 14 | Проверка и сохранение | Показывать реальные ответы/«только ознакомление». Идемпотентная запись с версионным server validator |
| 15 | Подтверждение и карта | Появляется **только после успешного ответа сервера**. XP только за участие, не за снижение симптомов |

**Минимальные разные учебные операции 8–12:** распознать → попробовать → вспомнить с меньшей поддержкой → выбрать в новом контексте → создать условный план. Заменять их пятью рейтинговыми вопросами запрещено.

## 3. Точечные поправки в живом плеере

- Пояснение ответа на экране 11 теперь зависит от **конкретного выбора**, а не от факта клика: для каждого из 14 дней, RU/EN — 3 отдельные реакции, всего 84 оригинальных пояснения.
- Экран 12 использует **другие варианты**, чем экран 9: всего 84 отдельные русско-английские формулировки планов. Запас «если не подходит — отдых / помощь / завершение» показывается отдельно и не является обещанием.
- Экран 9 объясняет, что выбрать карточку ≠ выполнить упражнение, экран 10 разрешает повтор лишь по выбору участника.
- Конкретная поддержка для шага **act**, **rehearse**, **notice**, **scenario**, а не одна общая длинная лекция.
- На 8/9 можно сообщить «Не пробовал» или «Некомфортно» даже **без выбора действия**. Заявить «Попробовал» без выбранного учебного шага всё ещё нельзя.
- Необязательный 0–10 ответ можно отменить повторным касанием числа. Пустой ответ = `null`, не ноль.
- В превью сохранения «Не пробовал» не называется совершённой попыткой. Публичная аналитика, диагнозы и проценты исцеления не генерируются.

## 4. Покрытие четырнадцати уроков

| Пара дней | Учебный навык | Пример недели 2 |
|---|---|---|
| 1 / 8 | Раннее распознавание спешки | Новый список повседневных дел и изменение внимания |
| 2 / 9 | Внешняя ориентировка | Новый холл / незнакомая комната, выбор нейтральной видимой детали |
| 3 / 10 | Бережная пауза | Различение многих требований и низкой энергии после разговора |
| 4 / 11 | Называние мягкого чувства | Персонаж сталкивается с обычным изменением планов |
| 5 / 12 | Факт vs тревожная догадка | Короткий ответ в групповом чате, выбор маленького ценностного шага |
| 6 / 13 | Уважительная граница | Повторная вымышленная просьба: короткий ответ без конфронтации |
| 7 / 14 | Самостоятельная карта ОПОРА | Выбор одной знакомой опоры и резервного варианта после занятого дня |

Ни один учебный кейс не требует реальной переписки, обязательного вызова тревоги, задержки дыхания, закрывания глаз, просмотра травматических воспоминаний или осознанного усиления эмоций. Для интенсивных симптомов и проработки травмы необходима соответствующая профессиональная помощь.

## 5. Код и контракт выпуска

- Содержание: `lib/inner-growth/opora-as55-learning-cases.js`, `lib/inner-growth/anti-stress-skills-v7.js`.
- Плеер: `components/app/opora-v6-slide-player.jsx` (общий безопасный 15-экранный UI, по version pinned данным).
- Новые циклы AS2: `lib/app/growth-daily.js` выбирает `COURSE_ANTISTRESS_SKILLS_V7`; V3/V5/V6 доступны по старому `content_version`.
- Сохранять только enum `opora54.answers/hints/ease` в owner-scoped сессии; они **не** являются клиническими показателями.
- CI: `tests/opora-as55-methodology-live.test.mjs` проверяет 14×RU/EN, реальный JSX-путь, отдельные варианты и объяснения, отсутствие ложного результата, совместимость и сертифицированную сервером последовательность 14 до сохранения + 1 после.

**Принципы обучения:** worked examples, постепенно уменьшаемая подсказка, повторное извлечение и перенос в новом случае; CAST UDL Guidelines 3.0; WHO `Doing What Matters in Times of Stress`; SAMHSA trauma-informed choice. Это основания для дизайна, **не клиническое доказательство эффективности ОПОРА**.
