**Критически важно:** изображения в первоначальном ответе показывались динамическим поисковым компонентом `AsyncImage.query` без зафиксированного ID исходного файла. Поэтому точные ранее показанные байты восстановить нельзя. Ниже сохранены **точные исходные поисковые описания** и выбранные по тому же сюжету лицензированные фотографии Unsplash. Эти 14 замен оформлены как самостоятельная стабильная подборка. Не говорить пользователю «это точно те же 14 файлов».

**Права:** все выбранные страницы просмотрены на предмет отметки `Free to use under the Unsplash License` (не Unsplash+); общие условия: https://unsplash.com/license . Фото из подборки предназначены для иллюстрирования уроков, не для создания фотобанка-конкурента. Атрибуция авторов желательна. При внедрении проверять изображения на читаемость/чувствительные ассоциации, лица и права модели, локальную лицензированную копию и CSS object-fit: contain/не обрезать лица и руки. Google Doc содержит сохранённые копии; прямые `images.unsplash.com` — источники для разработки, не каноническое хранилище сайта.

- Не публиковать исходники/превью без QA и лицензии.
