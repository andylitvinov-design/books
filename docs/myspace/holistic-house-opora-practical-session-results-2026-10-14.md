## Ориентиры полной длительности (ещё не измерены UX)
- Быстрый полный урок: **5–8 мин**.
- Обычный полный урок: **9–13 мин**.
- Первый интерактивный антистресс-урок: приблизительно **7–10 / 10–16 мин** (быстрый/обычный).
- Дополнительный глубокий вариант 13–18 мин — только если отдельно подготовлен безопасный добровольный сценарий; отсутствие его в UI не маскировать фальшивой кнопкой.
- Отдельный микрошаг может занимать 40–120 секунд, но это НЕ всё занятие. Цель пилота — 60% времени на реальном пользовательском опыте, а не анкетах и рекламных блоках. Ни одно время не является медицинской дозировкой.

## На что тратится время
1. Мягкий контакт и личная цель — коротко, без повторной батареи.
2. Подготовка реальной практики и нейтральная ориентировка — по выбору.
3. Одна главная направляемая практика (ориентир 2–4 мин по удобству).
4. Маленькое действие участника с интерактивными вариантами (не интерпретировать как диагностику).
5. Второй мягкий способ интеграции: слова/сцена/репетиция/внешняя опора, **не обязательный**.
6. Один честный результат и персональная настройка для будущих практик.

## Что является результатом ОДНОГО урока
Результат — не обещание облегчения. После server-confirmed save показывается `CourseLessonResult`, внутри прежнего completion-экрана:
- **Навык урока:** чему была посвящена образовательная работа (НЕ «освоено» автоматически).
- **Фактическая попытка:** исключительно ответ пользователя «попробовал/частично/остановился/не пробовал». Выбранные варианты `main`/`reflect` хранятся отдельно как выбор.
- **Моментная пара:** одинаковые оценки до/после guided-упражнения, только при обеих фактических точках, без причинного утверждения.
- **Комфортность, субъективная полезность, гибкость выбора:** независимые ответы; `skip` означает «не отмечено», а не «не попробовал».
- **Ресурс/ориентир и добровольная адаптация:** показывать только если реально выбран. Последующий тест курса — отдельная дата/инструмент.
- XP — за подтверждённое участие, а не симптоматический исход.

Данные `signals.practiceLab` содержат только проверенные идентификаторы `main, reflect, attempt` для конкретного дня; право владельца и сохранение существующей сессии не меняются. Свободные слова творческой практики в браузере НЕ сохраняются в серверную структуру сами; только кнопка «Добавить в личный дневник» копирует выбранный текст в существующее зашифрованное поле `reflection` при подтверждённом сохранении урока. Нет данных клиента в публичных медиа/аналитике.
