# CI workflow audit and invalid trigger cleanup (29 October 2026)

## Incident and evidence
Workflow runs generated by GitHub on ordinary feature branch pushes for `hh-my-progress-release.yml` and `practice-visual-services.yml` routinely ended `failure` with **zero jobs**, before any test execution. On two earlier PR #2549 SHAs (c50e3f6f, f774277e), API records show **two failing push runs each**, although the editor workflow has no push trigger. The first revised SHA `a2684c53` generated **ten pull_request workflows and zero failing push registrations**. This supports a trigger/glob registration repair, but continue monitoring after merge before declaring the underlying GitHub registration problem fully resolved.

## Corrective changes
- Replace ambiguous bracket-heavy Next.js route glob patterns with conservative `**` matches in My Progress and Practitioner editor; retain relevant PR scope.
- Avoid redundant feature-branch `push` runs in My Progress, while **keeping production branch push** and PR checks.
- The existing checksum-verified actionlint gate now performs two distinct validations: **all** YAML workflow syntax/expression contracts (`-shellcheck=` in this inventory step only) and **strict ShellCheck** on modified workflow files. Full baseline warning inventory found 27 pre-existing ShellCheck findings in 24 other workflows; those are not fixed by this PR and must be tracked separately. No global actionlint disable, ignore or check-bypass is added.
- Run unit regression contracts for trigger scope and dynamic route patterns.

## Rollout
Before merging, demand exact-head `actionlint-changed=success` and applicable `private-progress` and `service-editor` checks. Compare any unrelated App R1, OPORA, database or browser failures against the current production baseline; never call them green. On merge, read back the production SHA, inspect next 10–20 feature pushes for zero-job workflow failures, and verify no relevant workflow vanished. Do not independently enable GitHub native auto-merge: production branch ruleset and complete specialist aggregate must first be enforced.

## Future backlog
Repair pre-existing 27 ShellCheck findings in small module-owned batches, preserving retry behavior. Set a 7-day dashboard for failed zero-job runs, cancelled CI ratio, duplicate workflows per PR, median queue time, green-to-merge time, and distinct live-verified PRs.
