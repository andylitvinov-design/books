# Holistic House · Pro — четыре предложения для мастеров

Дата решения: 2026-10-24. Дизайн утверждён по скриншоту мобильного экрана `I'm a Master — offer services` от владельца. Связанные направления: Master Network [#715](https://github.com/andylitvinov-design/books/issues/715), Holistic Support [#1849](https://github.com/andylitvinov-design/books/issues/1849).

## Design of record (не менять на новую плиточную тему)
- Сохранять тёплый кремово-бежевый фон, коричневые рамки/акценты и крупную иерархию шрифта.
- Слева — реальные уже существующие фотографии сайта; справа — короткий заголовок, подзаголовок и стрелка.
- Большие закругления, фотографии с закруглёнными углами; компактная ширина 320–430 px; доступные кнопки от 44 px; нижняя навигация остаётся видимой.
- Выбранная категория визуально выделена, ниже — *пример* предложения и переход в **существующий** редактор; выбор карточки не создаёт сущность.
- EN основная, RU/ES семантически эквивалентны; не раскрывать частные клиентские данные в URL.

## Ровно четыре варианта в указанном порядке

| Категория EN | RU | ES | Реальное действие |
| --- | --- | --- | --- |
| Personal diagnostics | Персональная диагностика | Diagnóstico personal | `/app/practice?panel=services&create=1&starter=diagnostic`: `personal_development`, `assessment`, цена по запросу |
| Energy support | Энергетическая поддержка | Apoyo energético | `/app/practice?panel=services&create=1&starter=energy`: `energy_spiritual`, `session`, цена по запросу |
| Create a meditation course | Создать онлайн-курс медитации | Crear un curso de meditación | `/app/practice?panel=materials&materialTab=courses&create=1`: существующий редактор авторских учебных экранов и аудио/видео |
| Personal service | Персональная услуга | Servicio personal | `/app/practice?panel=services&create=1&starter=personal`: `personal_development`, `session`, цена по запросу |

Все маршруты имеют локализованный префикс `/en/`, `/ru/`; испанский публичный интерфейс использует уже существующий `/en/app` как защищённый кабинет. Старые закладки на `starter=session|intro|workshop` сохраняются работоспособными, но **не** отображаются как четыре основных предложения.

## Политика безопасности и целостности
- «Персональная диагностика» означает частный разбор/оценку запроса, **не** медицинский диагноз, лечение, назначение или обещание результата.
- Шаблон сервиса заполняет только существующий тип, область, онлайн-формат и цену «по запросу», не выдумывает цену, квалификацию или описание.
- При входе через Google сохраняется только разрешённое неперсональное значение `profi`; сервер проверяет allowlist; редакторы недоступны без авторизации, права и модерация остаются прежними.
- Обучающий курс — только черновик до сохранения автором и отдельного подтверждения публикации; видеоматериал добавляет сам мастер. **Не публиковать пустой курс без видео**; проверить этот продуктовый guard отдельно, если текущая система курсов его не гарантирует.
- Нет новых API, таблиц, платёжных провайдеров, уведомлений, лидов по нажатию или обещаний оплаченного заказа.

## Проверки и статус
1. Source regression: все четыре значения / 3 языка / фотография слева / правильные CTA и `aria-pressed`.
2. Deep links: гостевой Google OAuth, допустимые `starter`, закрытый кабинет, неавторизованный запрос, реальный редактор услуги/курса.
3. Безопасность: RLS и отдельная модерация публичной страницы, никаких личных сведений в query.
4. Typecheck, eslint, targeted tests, Next build, GitHub PR CI.
5. Production: проверка Vercel `READY`, Git SHA и alias `https://holistichouse.vercel.app`; EN/RU/ES и iPhone Safari 320/390/430; проверка создания *частного* черновика только владельцем с согласия.

**Не считать live/E2E подтверждённым только по PR, HTTP 200 или зелёному build.** Статус закрывать по фактическим проверкам, не создавать пробные публичные услуги или курсы от чужого имени.
