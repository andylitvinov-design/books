## Progress, feedback and history

Only a later date in the saved IANA time zone unlocks the next learning day. Fresh optional check-ins are required for a new session; skipping sends no ratings. Pauses and calendar gaps create no penalties or extra workload. Structured feedback can offer shorter or alternative/rest choices only after consent. Journal/reflection fields are optional, each limited to1,000 JavaScript code units, encrypted only on explicit per-submission storage opt-in.

Future plan edits require new explicit consent and both progress/plan revision checks. They start at the next unresolved day; deferred changes beyond that day are not supported. Completed lessons retain exact selected scale, practice bytes, language, version and goal-review bindings. Changing the UI language does not silently translate archived content. Day21 shows factual participation and optional check-in observations, voluntary exact-form retesting, neutral raw differences with prepared meanings, and a consented continuation of up to3 completed practices or a pause. No claim that the course caused score changes is made.

The local phrase matcher in the prior v1 UI is a bounded preference helper. General AI interpretation of arbitrary comments is still not connected. No provider/model, retention policy, budget, credential or named-recipient transmission consent has been approved for that purpose. The new v2 UI exposes prepared day choices, reversible structured-feedback preferences and the same bounded whole-note helper with a fresh explicit confirmation; private notes remain a readable journal. This does not close the broader AI-comment goal.

The accessible original article is abstract-only; it describes a four-item measure and studies in rheumatoid-arthritis samples. That does not establish general-population norms or validate this course. Do not turn it into a generic productivity goal. [Original article abstract](https://doi.org/10.1177/1073191103258144).

These are engineering/editorial priorities, not approved treatment recommendations or implemented mappings. Clinical screening, neutral traits, mixed-polarity composites and unsupported constructs remain informational until a defensible separately reviewed path exists.
