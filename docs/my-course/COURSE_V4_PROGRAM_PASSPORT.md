# Holistic House — My Course v4 · 14-day programme passport

**Status:** reviewed source/design specification for PR implementation. **Audience:** adult voluntary users; EN/RU; mobile-first. **Not** a clinical treatment, diagnostic tool, prescribed psychotherapy or guarantee of change.

## Design intention

The course is not fourteen unrelated meditations. It is one user-owned learning arc:

**My request → observe my response → find available support → practise one small choice → transfer to ordinary life → review and retain.**

The user's approved measured skill remains the core practice on spaced-repetition days. Other approved scales are auxiliary themes. The selected scales, measurements, baseline and personal notes never enter public HTML, ad analytics, AI providers or the URL.

**Original author-inspired layer:** imagery-psychotherapy as *voluntary metaphor*, safe symbolic objects, a 2-position paper resource map inspired by constellation work, bodily orientation without directed breathing, and five Wu Xing resource words used only as creative language: Water/rest, Wood/action, Fire/expression, Earth/support, Metal/boundaries. A Dao level, homeopathic remedy, illness, childhood cause or energetic deficit is never inferred from these exercises.

**Evidence-informed educational layer:** WHO brief self-help practice (grounding, unhooking, valued actions, making room, kindness); CCI sequential worksheets (recognize patterns, practise, review); ACT values and committed action; optional retrieval and cue-response / if-then planning. These **inform the structure**, not a claim that the original symbolic exercises have established efficacy.

### Progression

- **Days 1–3 — See clearly:** choose an ordinary goal, notice a pattern, learn to see a rigid rule as a hypothesis.
- **Days 4–6 — Grow room to choose:** external orientation, realistic alternative, a deliberately tiny safe experiment.
- **Day 7 — Review:** what was usable, what was uncomfortable, what needs a gentler option.
- **Days 8–11 — Bring it into life:** values, if-then cue, compare expectation with reality, choose support.
- **Days 12–13 — Build your own method:** simple resource palette, Plan B, select without instruction.
- **Day 14 — Integrate:** no false victory narrative; describe observed learning and plan the next 2–4 weeks.

## Lesson card passport (one calendar day, 5–12 minutes)

1. **Arrival / check-in (optional):** past-24h named concern 0–10 only when voluntarily saved; current mood never re-labelled as a validated test score. No catch-up zeros.
2. **Idea of the day:** original author-written reflection, skill objective, a believable working sentence, recall of a previously learned cue.
3. **Guided practice:** existing bilingual domain/day script; Quick or Standard; eyes open, natural breathing, stop/skip or no-imagery mode.
4. **Transfer / symbolic lab (optional):** one simple daily action *and* one short original symbolic image. Users can switch to words/real objects. No early-life memory work, trauma recall, compulsory exposure, claims that a symbol heals or diagnoses.
5. **Integration / notebook:** short question, editable personal one-line artifact, feedback (helpful/neutral/uncomfortable/skip), optional momentary before/after separate from past-24h measurement, encrypted account-owned journal.

**One action per screen:** burgundy current step / Save today; white secondary controls. No auto-playing media. The 14-day journey is discoverable but collapsible so today's step appears near the top on phones.

## Day and content integrity

- **R2:** original 84 × EN/RU lessons and IDs stay unchanged.
- **V3:** existing active cycles retain their pinned V3 lesson IDs, focus schedule and text.
- **V4:** only *new* cycles pin the V4 content identifier. New symbolic lab is additive: existing questions, provenance and server-side submitted lesson ID validation remain.
- Still 14 calendar days (Toronto/user account timezone and DST-safe local dates). A missed day stays missing; no catch-up penalty, fabricated rating or streak coercion.
- Day 7 and day 14 reviews stay explicit, with ordinary-language reflection on comfort and choice.
- A supportive low-intensity alternative must always be available; risk or severe distress requires real professional/emergency support, not self-help escalation.

## QA contract

- All 14 days have unique bilingual symbolism, metaphorical Wu Xing lenses, a 20–60 second plain-text alternative and a one-line journal artifact. No empty translations.
- Every one of the 84 domain/day combinations still returns actual reviewed educational texts. Domain-rotation and lesson-ID verification agree between server read and server submission for each content version and locale.
- Authenticated EN/RU mobile 320/390px: current lesson visible early, 14-day roadmap opens on demand; optional lab can expand without altering course state, completing or saving by itself.
- Legacy V2/V3 courses work untouched; every current user only sees their own authorized results, notes and planned scales.
- Compare descriptive trends only when enough nonmissing observations exist; don't imply symptom improvement or clinical effectiveness.
